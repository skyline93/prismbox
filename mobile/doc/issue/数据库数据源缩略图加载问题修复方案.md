**状态**: 待实施

**创建时间**: 2025-12-11  
**模块**: 媒体资源展示模块、本地媒体同步模块

## 问题概述

### 问题描述

在使用数据库数据源的情况下，照片页面的媒体缩略图没有展示出来。

### 问题表现

- 从数据库读取的 `LocalAsset` 对象的 `assetEntity` 字段为 `null`
- `ResourceSelectionStrategy.selectThumbnailProvider()` 方法在 `assetEntity` 为 `null` 时返回 `null`
- 导致无法创建 `LocalThumbProvider`，缩略图无法加载

### 问题根源

1. **数据源差异**：
   - 从 `photo_manager` 读取：`assetEntity` 直接可用
   - 从数据库读取：`assetEntity` 为 `null`（延迟获取策略未实现）

2. **架构设计不一致**：
   - 文档要求：延迟获取策略（方案A），在首次加载图片时获取 `AssetEntity`
   - 当前实现：`selectThumbnailProvider()` 是同步方法，无法处理异步获取
   - 缺少 `AssetEntity` 缓存机制

### 相关代码位置

- `lib/features/local_sync/services/timeline_provider_service.dart:96` - `assetEntity: null`
- `lib/features/media_loading/strategies/resource_selection_strategy.dart:79-89` - 返回 `null` 的逻辑
- `lib/features/media_loading/image_provider_factory.dart` - 资源选择工厂方法

### 方案架构图

```

│                    UI Layer                              │
│  MediaImageWidget → getThumbnailImageProviderAsync()     │
└─────────────────────────────────────────────────────────┘
                        │
                        ▼
┌─────────────────────────────────────────────────────────┐
│         ResourceSelectionStrategy Layer                  │
│  DefaultResourceSelectionStrategy                       │
│  ├─ shouldUseLocalAsset()                               │
│  ├─ selectThumbnailProvider() (同步，向后兼容)          │

│      ├─ asset.assetEntity != null → LocalThumbProvider  │

└─────────────────────────────────────────────────────────┘
                        │

│         AssetEntityLoader (新组件)                       │
│  ├─ loadAsync(LocalAsset) → Future<AssetEntity?>        │

│  ├─ 批量获取优化                                         │
│  └─ 加载 Future 缓存（避免重复请求）                    │
└─────────────────────────────────────────────────────────┘
                        │
                        ▼
┌─────────────────────────────────────────────────────────┐
│         TimelineProviderService                         │
│  ├─ getAssetEntityById() (已有)                         │
│  └─ 提供 AssetEntityLoader 访问                          │
└─────────────────────────────────────────────────────────┘
                        │
                        ▼
┌─────────────────────────────────────────────────────────┐
│         ImageProvider Layer                              │
│  LocalThumbProvider (使用 AssetEntity)                   │
└─────────────────────────────────────────────────────────┘
```

### 核心设计原则

1. **职责分离**：
   - `AssetEntityLoader`：负责 `AssetEntity` 的获取和缓存
   - `ResourceSelectionStrategy`：负责资源选择逻辑
   - `ImageProvider`：负责图片数据提供

2. **延迟获取策略**：
   - 按需获取：仅在需要加载图片时获取 `AssetEntity`
   - 缓存复用：避免重复获取相同的 `AssetEntity`
   - 批量优化：支持批量预加载

3. **向后兼容**：
   - 保留同步方法，不影响现有代码
   - 渐进式迁移，新代码使用异步版本

## 详细实现方案

### 1. AssetEntityLoader（核心组件）

**文件位置**: `lib/features/local_sync/services/asset_entity_loader.dart`

**职责**：
- 管理 `AssetEntity` 的延迟获取
- 提供 LRU 缓存机制（最多 200 个）
- 支持批量获取优化
- 统一访问入口

**实现要点**：

```dart
class AssetEntityLoader {
  // LRU 缓存（最多 200 个）
  final LinkedHashMap<String, AssetEntity> _cache = LinkedHashMap();
  
  // 正在加载的 Future 缓存（避免重复请求）
  final Map<String, Future<AssetEntity?>> _loadingFutures = {};
  
  /// 异步加载 AssetEntity
  /// 
  /// 策略：
  /// 1. 如果 LocalAsset 已有 assetEntity，直接返回
  /// 2. 检查缓存，命中则返回
  /// 3. 检查正在加载的 Future，避免重复请求
  /// 4. 调用 TimelineProviderService.getAssetEntityById() 获取
  /// 5. 缓存结果
  Future<AssetEntity?> loadAsync(LocalAsset asset);
  
  /// 批量加载 AssetEntity（用于预加载场景）
  Future<Map<String, AssetEntity?>> loadBatch(List<LocalAsset> assets);
  
  /// 清除缓存
  void clearCache();
}
```

**关键特性**：
- **LRU 缓存**：最近使用的 `AssetEntity` 保留在缓存中
- **Future 缓存**：避免同一 `AssetEntity` 的并发重复请求
- **批量加载**：支持预加载多个 `AssetEntity`，提升性能

2. **DefaultResourceSelectionStrategy 实现**：
```dart
class DefaultResourceSelectionStrategy implements ResourceSelectionStrategy {
  @override
  Future<ImageProvider?> selectThumbnailProviderAsync(
    BaseAsset asset, {
    required Size size,
    String? serverUrl,
    AssetEntityLoader? assetEntityLoader,
  }) async {
    if (shouldUseLocalAsset(asset)) {
      if (asset is LocalAsset) {
        // 如果 assetEntity 为 null，尝试异步获取
        if (asset.assetEntity == null) {
          if (assetEntityLoader != null) {
            final entity = await assetEntityLoader.loadAsync(asset);
            if (entity != null) {
              return LocalThumbProvider(
                asset: entity,
                size: size,
                cacheManager: thumbnailCacheManager,
                userId: userIdGetter?.call(asset),
                checksum: asset.checksum,
              );
            }
          }
          return null;
        } else {
          // 已有 assetEntity，直接使用
          return LocalThumbProvider(
            asset: asset.assetEntity!,
            size: size,
            cacheManager: thumbnailCacheManager,
            userId: userIdGetter?.call(asset),
            checksum: asset.checksum,
          );
        }
      }
      return null;
    } else {
      // 使用远程资源（同步）
      if (asset is RemoteAsset) {
        return RemoteThumbProvider(
          assetId: asset.id,
          size: size,
          serverUrl: serverUrl,
          cacheManager: thumbnailCacheManager,
        );
      }
    }
    return null;
  }
}
```

### 3. 扩展 image_provider_factory

**文件位置**: `lib/features/media_loading/image_provider_factory.dart`

**修改内容**：

添加异步版本的工厂方法：

```dart
/// 获取缩略图提供者（异步版本，支持延迟获取 AssetEntity）
/// 
/// 当 LocalAsset 的 assetEntity 为 null 时，会自动异步获取
Future<ImageProvider?> getThumbnailImageProviderAsync(
  BaseAsset asset, {
  Size size = kThumbnailResolution,
  String? serverUrl,
  ApiService? apiService,
  ThumbnailImageCacheManager? thumbnailCacheManager,
  ResourceSelectionStrategy? strategy,
  AssetEntityLoader? assetEntityLoader,
}) async {
  final selectedStrategy = strategy ?? _getDefaultStrategy();
  
  if (selectedStrategy is DefaultResourceSelectionStrategy) {
    selectedStrategy.thumbnailCacheManager = thumbnailCacheManager;
  }
  
  return await selectedStrategy.selectThumbnailProviderAsync(
    asset,
    size: size,
    serverUrl: serverUrl,
    assetEntityLoader: assetEntityLoader,
  );
}
```

**注意**：保留原有的同步方法 `getThumbnailImageProvider()`，保持向后兼容。

```dart
Future<void> _loadImageProvider() async {
  final targetSize = widget.size ?? 
      (widget.isThumbnail ? kThumbnailResolution : const Size(1080, 1920));
  
  setState(() {
    _isLoading = true;
  });
  
  try {
    // 获取 AssetEntityLoader
    final assetEntityLoader = widget.assetEntityLoader;
    
    // 尝试异步获取
    if (assetEntityLoader != null && widget.asset is LocalAsset) {
      final localAsset = widget.asset as LocalAsset;
      if (localAsset.assetEntity == null) {
        // 使用异步版本
        _imageProvider = await getThumbnailImageProviderAsync(
          widget.asset,
          size: targetSize,
          serverUrl: widget.serverUrl,
          assetEntityLoader: assetEntityLoader,
        );
      } else {
        // 已有 assetEntity，使用同步版本
        _imageProvider = widget.isThumbnail
            ? getThumbnailImageProvider(
                widget.asset,
                size: targetSize,
                serverUrl: widget.serverUrl,
              )
            : getFullImageProvider(
                widget.asset,
                size: targetSize,
                loadOriginal: widget.loadOriginal,
                serverUrl: widget.serverUrl,
              );
      }
    } else {
      // 非 LocalAsset 或没有 loader，使用同步版本
      _imageProvider = widget.isThumbnail
          ? getThumbnailImageProvider(
              widget.asset,
              size: targetSize,
              serverUrl: widget.serverUrl,
            )
          : getFullImageProvider(
              widget.asset,
              size: targetSize,
              loadOriginal: widget.loadOriginal,
              serverUrl: widget.serverUrl,
            );
    }
  } finally {
    if (mounted) {
      setState(() {
        _isLoading = false;
      });
    }
  }
}
```

3. **处理加载状态**：
在 `build` 方法中，当 `_isLoading` 为 `true` 时显示加载指示器。

/// AssetEntityLoader Provider
/// 
/// 提供 AssetEntity 的延迟获取和缓存功能

## 注意事项

### 1. 错误处理

**场景**：`AssetEntity` 获取失败

**处理策略**：
- 返回 `null`，由 `MediaImageWidget` 显示占位符
- 记录错误日志，便于排查问题
- 不抛出异常，避免影响其他图片加载

**实现示例**：
```dart
Future<AssetEntity?> _loadAssetEntity(String assetId) async {
  try {
    return await _timelineProviderService.getAssetEntityById(assetId);
  } catch (e) {
    _logger.warning('Failed to load AssetEntity: $assetId', e);
    return null; // 返回 null，不抛出异常
  }
}
```

### 2. 内存管理

**缓存大小限制**：
- LRU 缓存最多 200 个 `AssetEntity`
- 超出限制时自动淘汰最久未使用的
- 应用退出时清理缓存

**实现要点**：
```dart
void _cacheAssetEntity(String assetId, AssetEntity entity) {
  // 如果缓存已满，移除最久未使用的
  if (_cache.length >= _maxCacheSize && !_cache.containsKey(assetId)) {
    final firstKey = _cache.keys.first;
    _cache.remove(firstKey);
  }
  
  _cache[assetId] = entity;
}
```

### 3. 性能优化

**批量加载**：
- 在可见区域预加载相邻图片的 `AssetEntity`
- 使用 `loadBatch()` 方法批量获取，减少调用次数

**Future 缓存**：
- 避免同一 `AssetEntity` 的并发重复请求
- 多个组件同时请求同一资源时，共享同一个 Future

### 4. 向后兼容

**保持同步方法**：
- 保留 `selectThumbnailProvider()` 同步方法
- 保留 `getThumbnailImageProvider()` 同步工厂方法
- 现有代码不受影响

**渐进式迁移**：
- 新代码使用异步版本
- 旧代码继续使用同步版本
- 逐步迁移到异步版本

### 5. 监控和调试

**缓存统计**：
- 提供 `getCacheStats()` 方法获取缓存统计信息
- 包括缓存大小、加载中的数量等
