### 3. 数据源切换后的刷新未实现（中优先级）

**模块**: 本地媒体同步模块  
**位置**: `lib/presentation/pages/photos/main_timeline_page.dart`  
**状态**: ✅ 已修复（2025-12-11）

#### 问题描述

设计文档要求（`doc/modules/本地媒体同步模块详细设计文档.md:325-327, 588-590`）在同步完成后，如果数据库数据可用，应刷新时间线数据，自动切换到数据库数据源。

**当前实现**:
- `SyncCoordinator` 中已实现 `dataSourceSwitchStream`（第47行）
- 同步成功后会调用 `_checkAndSwitchDataSource()`（第143行）
- 如果数据库数据可用，会通过 `_dataSourceSwitchController.add(true)` 发送通知（第200行）
- **但未找到监听 `dataSourceSwitchStream` 的代码**
- `MainTimelinePage` 中未监听数据源切换
- 未找到 `invalidate(timelineSectionsProvider)` 的调用

#### 影响

1. **数据源切换不生效**
   - 同步完成后，即使数据库数据可用，UI 仍使用 photo_manager 数据源
   - 无法享受数据库查询的性能优势
   - 不符合设计文档的优化策略

2. **用户体验**
   - 首次同步后，用户需要手动刷新才能看到优化后的数据源
   - 无法自动享受性能提升

#### 设计文档要求

**切换策略**:
- **平滑切换**：同步完成后，刷新时间线数据，自动切换到数据库
- **用户无感知**：切换过程对用户透明
- **提升性能**：后续数据获取从数据库读取，性能更好

**数据流**:
```
同步完成
  ↓
检查数据库数据充足性
  ├─→ 数据充足（> 阈值）
  │   └─→ 切换到数据库数据源
  │       └─→ 刷新 TimelineProvider
  │
  └─→ 数据不足（≤ 阈值）
      └─→ 保持 photo_manager 数据源
```

#### 修复方案

**方案A：在 MainTimelinePage 中监听（推荐）**

**文件**: `lib/presentation/pages/photos/main_timeline_page.dart`

**需要修改的代码**:
```dart
class _MainTimelinePageState extends ConsumerState<MainTimelinePage> {
  final ScrollController _scrollController = ScrollController();
  StreamSubscription<bool>? _dataSourceSwitchSubscription;

  @override
  void initState() {
    super.initState();
    // 监听数据源切换
    _listenDataSourceSwitch();
  }

  @override
  void dispose() {
    _dataSourceSwitchSubscription?.cancel();
    _scrollController.dispose();
    super.dispose();
  }

  /// 监听数据源切换通知
  void _listenDataSourceSwitch() {
    ref.read(syncCoordinatorProvider.future).then((coordinator) {
      _dataSourceSwitchSubscription = coordinator.dataSourceSwitchStream.listen(
        (shouldSwitch) {
          if (shouldSwitch && mounted) {
            // 刷新时间线数据，触发数据源切换
            ref.invalidate(timelineSectionsProvider);
            // 可选：显示提示信息
            ScaffoldMessenger.of(context).showSnackBar(
              const SnackBar(
                content: Text('数据已同步完成'),
                duration: Duration(seconds: 2),
              ),
            );
          }
        },
        onError: (error) {
          // 记录错误但不影响功能
          debugPrint('数据源切换监听错误: $error');
        },
      );
    });
  }

  // ... 其他代码保持不变
}
```

**方案C：通过 Provider 自动响应（最佳方案，但需要重构）**

创建一个新的 Provider 来监听数据源切换并自动刷新：

**文件**: `lib/features/local_sync/providers/timeline_provider.dart`

```dart
/// 数据源切换监听 Provider
/// 自动监听数据源切换并刷新时间线数据
@riverpod
class DataSourceSwitchListener extends _$DataSourceSwitchListener {
  StreamSubscription<bool>? _subscription;

  @override
  void build() {
    // 监听数据源切换
    ref.onDispose(() {
      _subscription?.cancel();
    });

    ref.read(syncCoordinatorProvider.future).then((coordinator) {
      _subscription = coordinator.dataSourceSwitchStream.listen(
        (shouldSwitch) {
          if (shouldSwitch) {
            // 刷新时间线数据
            ref.invalidate(timelineSectionsProvider);
          }
        },
      );
    });
  }
}
```
