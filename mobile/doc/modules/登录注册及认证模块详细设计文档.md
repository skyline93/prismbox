## 模块概述

### 职责范围

登录注册及认证模块是 PrismBox 移动端的用户身份认证核心，负责：

1. **用户注册**
   - 新用户账号创建
   - 注册信息验证
   - 注册成功后自动登录

2. **用户登录**
   - 邮箱密码登录
   - Token 获取和管理
   - 用户信息同步到本地数据库

3. **认证管理**
   - Access Token 和 Refresh Token 存储
   - Token 自动刷新机制
   - 401 错误自动处理和登录跳转

4. **用户信息管理**
   - 获取用户资料
   - 用户信息本地缓存
   - 用户信息与资产/相册关联

5. **登出功能**
   - Token 撤销
   - 本地数据清理
   - 跳转登录页

### 核心目标

1. **安全可靠**：Token 安全存储，自动刷新，防止未授权访问
2. **用户体验**：流畅的登录注册流程，友好的错误提示
3. **数据一致性**：用户信息同步到本地数据库，建立数据关联关系
4. **离线支持**：用户信息本地缓存，支持离线查看
5. **易于扩展**：支持多用户、第三方登录（如 Apple 登录）等扩展

### 设计原则

1. **统一管理**：所有认证相关操作通过 AuthService 统一管理
2. **自动处理**：Token 自动注入、自动刷新、401 自动跳转
3. **数据持久化**：用户信息保存到本地数据库，建立数据关联
4. **安全优先**：Token 存储在平台安全存储（Keychain/Keystore）
5. **错误友好**：统一的错误处理，用户友好的错误提示

## 核心组件详解

### AuthService

#### 职责

AuthService 是认证模块的核心服务，负责：

1. **登录注册业务逻辑**
   - 用户登录
   - 用户注册
   - 注册成功后自动登录

2. **Token 管理**
   - Token 存储和获取
   - Token 刷新
   - Token 清除

3. **用户信息管理**
   - 获取用户资料
   - 用户信息本地持久化
   - 用户信息更新

4. **认证状态管理**
   - 检查登录状态
   - 验证 Token 有效性

#### 接口定义

```dart
class AuthService {
  // ========== 登录注册 ==========
  
  /// 用户登录
  /// 
  /// [email] 邮箱地址
  /// [password] 密码
  /// 
  /// 返回 [AuthResult] 包含登录结果和用户信息
  Future<AuthResult> login(String email, String password);
  
  /// 用户注册
  /// 
  /// [username] 用户名
  /// [email] 邮箱地址
  /// [password] 密码
  /// 
  /// 返回 [RegisterResult] 包含注册结果
  Future<RegisterResult> register({
    required String username,
    required String email,
    required String password,
  });
  
  // ========== Token 管理 ==========
  
  /// 刷新访问令牌
  /// 
  /// [refreshToken] 刷新令牌
  /// 
  /// 返回新的访问令牌
  Future<String> refreshToken(String refreshToken);
  
  /// 登出
  /// 
  /// 撤销刷新令牌并清除本地认证信息
  Future<void> logout();
  
  // ========== 用户信息 ==========
  
  /// 获取用户资料
  /// 
  /// 返回当前登录用户的资料信息
  Future<UserProfile> getProfile();
  
  /// 检查登录状态
  /// 
  /// 返回 true 如果用户已登录且 Token 有效
  Future<bool> isAuthenticated();
  
  // ========== 认证信息管理 ==========
  
  /// 清除认证信息
  /// 
  /// 清除 Token 和本地用户数据
  Future<void> clearAuth();
}
```

#### 实现要点

**1. 登录实现**

```dart
class AuthService {
  final AuthRepository _repository;
  final ApiService _apiService;
  final SecureStorageService _secureStorage;
  final UserDao _userDao;
  
  /// 用户登录
  Future<AuthResult> login(String email, String password) async {
    try {
      // 1. 调用登录 API
      final request = LoginRequestDto(email: email, password: password);
      final response = await _repository.login(request);
      
      // 2. 保存 Token
      await _apiService.setAccessToken(response.accessToken);
      await _secureStorage.setRefreshToken(response.refreshToken);
      
      // 3. 获取用户资料
      final profile = await getProfile();
      
      // 4. 保存用户信息到本地数据库
      await _saveUserToDatabase(profile);
      
      return AuthResult.success(profile);
    } on ApiException catch (e) {
      if (e.statusCode == 401) {
        return AuthResult.failure('邮箱或密码错误');
      }
      return AuthResult.failure(e.message);
    } catch (e) {
      return AuthResult.failure('登录失败: $e');
    }
  }
  
  /// 保存用户信息到本地数据库
  Future<void> _saveUserToDatabase(UserProfile profile) async {
    try {
      final userEntity = UserEntityData(
        id: profile.id.toString(),
        name: profile.username ?? profile.email,
        email: profile.email,
        avatarUrl: profile.avatarUrl,
        createdAt: profile.createdAt ?? DateTime.now(),
        updatedAt: DateTime.now(),
      );
      
      // 检查用户是否已存在
      final existingUser = await _userDao.getUserById(userEntity.id);
      
      if (existingUser != null) {
        // 更新现有用户
        await _userDao.updateUser(userEntity);
      } else {
        // 插入新用户
        await _userDao.insertUser(userEntity);
      }
    } catch (e) {
      // 记录错误但不影响登录流程
      _log.warning('Failed to save user to database: $e');
    }
  }
}
```

**2. 注册实现**

```dart
class AuthService {
  /// 用户注册
  Future<RegisterResult> register({
    required String username,
    required String email,
    required String password,
  }) async {
    try {
      // 1. 调用注册 API
      final request = RegisterRequestDto(
        username: username,
        email: email,
        password: password,
      );
      final response = await _repository.register(request);
      
      // 2. 注册成功后自动登录
      final loginResult = await login(email, password);
      
      if (loginResult.isSuccess) {
        return RegisterResult.success(loginResult.user!);
      } else {
        return RegisterResult.failure(loginResult.errorMessage ?? '注册成功，但登录失败');
      }
    } on ApiException catch (e) {
      if (e.statusCode == 400 || e.statusCode == 409) {
        return RegisterResult.failure('用户名或邮箱已存在');
      }
      return RegisterResult.failure(e.message);
    } catch (e) {
      return RegisterResult.failure('注册失败: $e');
    }
  }
}
```

**3. Token 刷新实现**

```dart
class AuthService {
  /// 刷新访问令牌
  Future<String> refreshToken(String refreshToken) async {
    try {
      final response = await _repository.refreshToken(refreshToken);
      await _apiService.setAccessToken(response.accessToken);
      return response.accessToken;
    } on ApiException catch (e) {
      if (e.statusCode == 401) {
        // 刷新令牌失效，清除认证信息
        await clearAuth();
      }
      rethrow;
    }
  }
}
```

**4. 登出实现**

```dart
class AuthService {
  /// 登出
  Future<void> logout() async {
    try {
      // 1. 获取刷新令牌
      final refreshToken = await _secureStorage.getRefreshToken();
      
      // 2. 调用登出 API（撤销刷新令牌）
      if (refreshToken != null) {
        await _repository.logout(refreshToken);
      }
    } catch (e) {
      // 即使登出 API 调用失败，也清除本地认证信息
      _log.warning('Logout API call failed: $e');
    } finally {
      // 3. 清除本地认证信息
      await clearAuth();
    }
  }
  
  /// 清除认证信息
  Future<void> clearAuth() async {
    await _apiService.clearAccessToken();
    await _secureStorage.deleteAccessToken();
    await _secureStorage.deleteRefreshToken();
    
    // 注意：不清除本地用户数据，因为：
    // 1. 支持多用户场景
    // 2. 用户数据可能被其他数据引用（资产、相册等）
    // 如果需要清除，可以在登出时显式调用
  }
}
```

### AuthRepository

#### 职责

AuthRepository 负责封装认证相关的 API 调用：

   - 登出 API

2. **数据转换**
   - Request DTO → JSON
   - Response JSON → DTO

3. **错误处理**

#### 实现要点

```dart
class AuthRepositoryImpl implements AuthRepository {
  final ApiService _apiService;
  
  AuthRepositoryImpl(this._apiService);
  
  @override
  Future<AuthResponseDto> login(LoginRequestDto request) async {
    try {
      final response = await _apiService.dio.post(
        '/v1/auth/login',
        data: request.toJson(),
      );
      
      // ResponseInterceptor 已自动提取 data 字段
      return AuthResponseDto.fromJson(response.data as Map<String, dynamic>);
    } on DioException catch (e) {
      throw _handleError(e);
    }
  }
  
  @override
  Future<RegisterResponseDto> register(RegisterRequestDto request) async {
    try {
      final response = await _apiService.dio.post(
        '/v1/auth/register',
        data: request.toJson(),
      );
      
      return RegisterResponseDto.fromJson(response.data as Map<String, dynamic>);
    } on DioException catch (e) {
      throw _handleError(e);
    }
  }
  
  @override
  Future<RefreshTokenResponseDto> refreshToken(String refreshToken) async {
    try {
      final response = await _apiService.dio.post(
        '/v1/auth/refresh',
        data: {'refresh_token': refreshToken},
      );
      
      return RefreshTokenResponseDto.fromJson(response.data as Map<String, dynamic>);
    } on DioException catch (e) {
      throw _handleError(e);
    }
  }
  
  @override
  Future<void> logout(String refreshToken) async {
    try {
      await _apiService.dio.post(
        '/v1/auth/logout',
        data: {'refresh_token': refreshToken},
      );
    } on DioException catch (e) {
      throw _handleError(e);
    }
  }
  
  @override
  Future<UserProfileDto> getProfile() async {
    try {
      final response = await _apiService.dio.get('/v1/auth/profile');
      return UserProfileDto.fromJson(response.data as Map<String, dynamic>);
    } on DioException catch (e) {
      throw _handleError(e);
    }
  }
  
  ApiException _handleError(DioException e) {
    if (e.response != null) {
      final statusCode = e.response!.statusCode ?? 500;
      final message = e.response!.data?['message'] ?? '请求失败';
      return ApiException(statusCode, message);
    }
    return ApiException(503, '网络错误: ${e.message}');
  }
}
```

### AuthProvider

#### 职责

AuthProvider 负责管理认证状态，提供响应式状态更新：

1. **状态管理**
   - 认证状态（已登录/未登录）
   - 用户信息
   - 加载状态
   - 错误信息

2. **状态监听**
   - 登录状态变化监听
   - 用户信息变化监听

#### 状态定义

```dart
/// 认证状态
@freezed
class AuthState with _$AuthState {
  /// 初始状态
  const factory AuthState.initial() = _Initial;
  
  /// 已认证（包含用户信息）
  const factory AuthState.authenticated(UserProfile user) = _Authenticated;
  
  /// 未认证
  const factory AuthState.unauthenticated() = _Unauthenticated;
  
  /// 加载中
  const factory AuthState.loading() = _Loading;
  
  /// 错误状态
  const factory AuthState.error(String message) = _Error;
```

#### 实现要点

```dart
/// 认证状态管理器
class AuthNotifier extends StateNotifier<AuthState> {
  final AuthService _authService;
  
  AuthNotifier(this._authService) : super(const AuthState.initial()) {
    _initialize();
  }
  
  /// 初始化：检查登录状态
  Future<void> _initialize() async {
    state = const AuthState.loading();
    
    try {
      final isAuthenticated = await _authService.isAuthenticated();
      if (isAuthenticated) {
        final profile = await _authService.getProfile();
        state = AuthState.authenticated(profile);
      } else {
        state = const AuthState.unauthenticated();
      }
    } catch (e) {
      state = AuthState.error('初始化失败: $e');
    }
  }
  
  /// 登录
  Future<void> login(String email, String password) async {
    state = const AuthState.loading();
    
    try {
      final result = await _authService.login(email, password);
      if (result.isSuccess) {
        state = AuthState.authenticated(result.user!);
      } else {
        state = AuthState.error(result.errorMessage ?? '登录失败');
      }
    } catch (e) {
      state = AuthState.error('登录失败: $e');
    }
  }
  
  /// 注册
  Future<void> register({
    required String username,
    required String email,
    required String password,
  }) async {
    state = const AuthState.loading();
    
    try {
      final result = await _authService.register(
        username: username,
        email: email,
        password: password,
      );
      if (result.isSuccess) {
        state = AuthState.authenticated(result.user!);
      } else {
        state = AuthState.error(result.errorMessage ?? '注册失败');
      }
    } catch (e) {
      state = AuthState.error('注册失败: $e');
    }
  }
  
  /// 登出
  Future<void> logout() async {
    state = const AuthState.loading();
    
    try {
      await _authService.logout();
      state = const AuthState.unauthenticated();
    } catch (e) {
      state = AuthState.error('登出失败: $e');
    }
  }
}
```

## 数据流设计

### 登录流程

```
用户输入邮箱和密码
    ↓
LoginPage 调用 AuthService.login()
    ↓
AuthService 创建 LoginRequestDto
    ↓
AuthRepository.login() 调用 API
    ↓
ApiService.dio.post('/v1/auth/login')
    ↓
_AuthInterceptor 注入认证头（如果有）
    ↓
_ResponseInterceptor 解析响应格式
    ↓
返回 AuthResponseDto (access_token, refresh_token)
    ↓
AuthService 保存 Token
    ├─ ApiService.setAccessToken() → Store + SecureStorage
    └─ SecureStorage.setRefreshToken() → SecureStorage
    ↓
AuthService 调用 getProfile() 获取用户信息
    ↓
AuthRepository.getProfile() 调用 API
    ↓
返回 UserProfileDto
    ↓
AuthService 保存用户信息到本地数据库
    ├─ UserDao.getUserById() 检查是否存在
    ├─ UserDao.insertUser() 或 updateUser()
    └─ 建立用户与资产/相册的关联关系
    ↓
返回 AuthResult.success(user)
    ↓
AuthProvider 更新状态为 authenticated
    ↓
UI 导航到主页 (TabShellRoute)
```

### 注册流程

```
用户输入用户名、邮箱和密码
    ↓
RegisterPage 调用 AuthService.register()
    ↓
AuthService 创建 RegisterRequestDto
    ↓
AuthRepository.register() 调用 API
    ↓
ApiService.dio.post('/v1/auth/register')
    ↓
返回 RegisterResponseDto (user_id, username)
    ↓
注册成功后自动调用 login()
    ↓
执行登录流程（同上）
    ↓
返回 RegisterResult.success(user)
    ↓
AuthProvider 更新状态为 authenticated
    ↓
UI 导航到主页 (TabShellRoute)
```

### 启动页认证检查流程

```
应用启动 (SplashPage)
    ↓
从 SecureStorage 获取 AccessToken
    ↓
Token 是否存在？
    ├─ 否 → 导航到登录页
    └─ 是 → 继续
    ↓
ApiService.setAccessToken(token)
    ↓
ApiService.pingServer() 验证 Token
    ↓
Token 是否有效？
    ├─ 否 (401) → 清除 Token → 导航到登录页
    └─ 是 → 继续
    ↓
AuthService.getProfile() 获取用户信息
    ↓
检查本地数据库是否有用户信息
    ├─ 否 → 保存用户信息到数据库
    └─ 是 → 更新用户信息（可选）
    ↓
导航到主页 (TabShellRoute)
```

### Token 自动刷新流程

```
API 请求返回 401 错误
    ↓
_ErrorInterceptor 捕获 401 错误
    ↓
检查是否有 RefreshToken
    ├─ 否 → 清除认证信息 → 触发回调 → 跳转登录页
    └─ 是 → 继续
    ↓
调用 AuthService.refreshToken()
    ↓
AuthRepository.refreshToken() 调用 API
    ↓
返回新的 AccessToken
    ↓
保存新的 AccessToken
    ↓
重试原请求（使用新的 AccessToken）
    ↓
返回响应或错误
```

### 登出流程

```
用户点击登出
    ↓
AuthService.logout()
    ↓
从 SecureStorage 获取 RefreshToken
    ↓
调用 AuthRepository.logout() 撤销令牌
    ↓
清除本地认证信息
    ├─ ApiService.clearAccessToken()
    ├─ SecureStorage.deleteAccessToken()
    └─ SecureStorage.deleteRefreshToken()
    ↓
AuthProvider 更新状态为 unauthenticated
    ↓
UI 导航到登录页
```

#### 统一错误处理

```dart
/// 认证错误处理工具
class AuthErrorHandler {
  /// 处理认证错误并返回用户友好的消息
  static String getErrorMessage(dynamic error) {
    if (error is AuthenticationException) {
      return '邮箱或密码错误';
    }
    
    if (error is RegistrationException) {
      if (error.message.contains('already exists')) {
        return '用户名或邮箱已存在';
      }
      return '注册失败，请检查输入信息';
    }
    
    if (error is TokenRefreshException) {
      return '登录已过期，请重新登录';
    }
    
    if (error is ApiException) {
      return _getApiErrorMessage(error);
    }
    
    if (error is SocketException) {
      return '网络连接失败，请检查网络设置';
    }
    
    if (error is TimeoutException) {
      return '请求超时，请稍后重试';
    }
    
    return '发生未知错误，请稍后重试';
  }

  static String _getApiErrorMessage(ApiException error) {
    switch (error.statusCode) {
      case 401:
        return '登录已过期，请重新登录';
      case 400:
        return '请求参数错误';
      case 409:
        return '用户名或邮箱已存在';
      case 500:
      case 502:
      case 503:
        return '服务器错误，请稍后重试';
      case 504:
        return '请求超时，请稍后重试';
      default:
        return error.message;
    }
  }

  /// 处理认证错误并执行相应操作
  static Future<void> handleError(dynamic error, BuildContext? context) async {
    if (error is AuthenticationException || error is TokenRefreshException) {
      // 401 错误：清除认证信息并跳转登录
      final authService = GetIt.instance<AuthService>();
      await authService.clearAuth();
      
      if (context != null) {
        // 跳转到登录页
        // context.router.pushAndClearStack(const LoginRoute());
      }
    } else if (error is RegistrationException) {
      // 注册错误：显示提示
      if (context != null) {
        ScaffoldMessenger.of(context).showSnackBar(
          SnackBar(
            content: Text(getErrorMessage(error)),
            backgroundColor: Colors.red,
          ),
        );
      }
    }
  }
}
```

```dart
    if (useCache) {

    // 3. 更新本地缓存
    await _saveUserToDatabase(profile);
    
    return profile;
  }
```

### 请求优化

#### 避免重复请求

```dart
class AuthService {
  Future<UserProfile>? _profileFuture;
  
  /// 获取用户资料（去重）
  Future<UserProfile> getProfile() async {
    // 如果已有正在进行的请求，等待它完成
    if (_profileFuture != null) {
      return await _profileFuture!;
    }
    
    // 创建新请求
    _profileFuture = _fetchProfile();
    
    try {
      return await _profileFuture!;
    } finally {
      _profileFuture = null;
    }
  }
  
  Future<UserProfile> _fetchProfile() async {
    final dto = await _repository.getProfile();
    final profile = UserProfile.fromDto(dto);
    await _saveUserToDatabase(profile);
    return profile;
  }
}
```

### 常见问题和解决方案

#### 问题 1：登录后用户信息未保存到数据库

**症状**：登录成功但查询不到用户信息

**解决方案**：
1. 检查 `_saveUserToDatabase` 方法是否被调用
2. 检查 UserDao 的 insertUser/updateUser 方法
3. 检查用户 ID 转换是否正确（int → String）
4. 查看日志确认是否有错误

#### 问题 2：Token 刷新失败导致频繁登录

**症状**：应用使用一段时间后需要重新登录

**解决方案**：
1. 检查 RefreshToken 是否正确存储
2. 检查 Token 刷新逻辑是否正确
3. 检查 RefreshToken 是否过期
4. 增加 Token 刷新日志

#### 问题 3：401 错误未自动跳转登录

**症状**：Token 失效后未自动跳转登录页

**解决方案**：
1. 检查 ApiService 的 401 错误处理
2. 检查 onUnauthorizedCallback 是否设置
3. 检查路由守卫是否正确配置
4. 检查错误拦截器顺序

#### 问题 4：注册后自动登录失败

**症状**：注册成功但未自动登录

**解决方案**：
1. 检查注册 API 返回的数据格式
2. 检查自动登录逻辑
3. 检查 Token 是否正确保存
4. 查看日志确认错误信息
