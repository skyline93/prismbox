## 实施总览

### 实施目标

实现完整的备份功能，包括：
1. **手动备份**：用户主动选择资源立即备份
2. **自动备份**：系统根据配置自动触发备份
3. **后台任务**：独立 Engine 架构，不影响主应用
4. **上传队列**：并发控制、优先级管理、断点续传
5. **错误处理**：完善的错误处理和重试机制

### 实施周期

总计：**12-16 周**（分 6 个阶段）

### 模块依赖关系

```
数据库模块（已存在）
    ↓
API 对接模块（已存在）
    ↓
本地媒体同步模块（已存在）
    ↓
备份功能模块（待实施）
    ├─→ 数据层（数据库表、DAO）
    ├─→ 服务层（BackupService、UploadService 等）
    ├─→ 后台任务层（BackgroundWorkerBgService）
    └─→ 平台原生层（Android WorkManager、iOS BGTaskScheduler）
```

#### 任务 1.1：数据库表设计与实现（3-4 天）

**文件位置**：
- `lib/data/database/tables/backup_status_entity.dart`
- `lib/data/database/tables/upload_task_entity.dart`
- `lib/data/database/daos/backup_status_dao.dart`
- `lib/data/database/daos/upload_task_dao.dart`

**实施步骤**：
1. 创建 `backup_status_entity.dart`
   - 定义 `BackupStatusEntity` 表
   - 字段：`userId`（主键）、`lastBackupTime`、`enabled`、`autoBackupMode`、`timeRangeStart`、`timeRangeEnd`
   - 外键约束：`userId` → `UserEntity.id` (CASCADE DELETE)
2. 创建 `upload_task_entity.dart`
   - 定义 `UploadTaskEntity` 表
   - 字段：`id`（主键）、`userId`、`assetId`、`taskType`、`priority`、`status`、`retryCount`、`maxRetries` 等

4. 在 `app_database.dart` 中注册表和 DAO
