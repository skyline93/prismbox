## 模块概述

### 职责范围

照片时间线展示模块是 PrismBox 移动端的核心展示模块，负责：

1. **时间分组展示**：将照片按时间（年/月/日）进行分组，提供清晰的时间线浏览体验
2. **分组标题显示**：为每个时间段提供友好的标题显示（如"今天"、"昨天"、"2024年1月"等）
3. **媒体网格渲染**：在每个时间段内以网格形式展示照片和视频
4. **滚动性能优化**：支持大量数据的流畅滚动，使用虚拟滚动技术
5. **快速定位**：支持快速跳转到指定日期或时间段
6. **交互增强**：提供分组展开/折叠、日期跳转等交互功能

### 核心目标

1. **清晰的时间线展示**：用户能够快速理解照片的时间分布
2. **流畅的滚动体验**：即使有数千张照片，也能保持流畅的滚动性能
3. **快速加载**：优先显示最近的照片，按需加载历史数据
4. **友好的时间显示**：使用自然语言描述时间（今天、昨天、本周等）
5. **内存优化**：严格控制内存使用，及时释放不可见区域的资源

### 设计原则

1. **渐进式分组**：根据时间远近采用不同的分组粒度（最近按天，较远按月/年）
2. **虚拟滚动**：只渲染可见区域的内容，避免一次性加载所有数据
3. **懒加载**：分组和媒体内容都采用懒加载策略
4. **性能优先**：在保证功能的前提下，优先考虑性能优化
5. **用户体验**：提供流畅的滚动和清晰的视觉层次

### 与其他模块的关系

```
照片时间线展示模块
    │
    ├─→ 本地媒体同步模块：获取 BaseAsset 数据列表（timelineAssetsProvider）
    ├─→ 媒体资源展示模块：使用 MediaGridSliver 渲染媒体网格
    ├─→ 页面导航模块：作为照片页面的主要展示组件
    └─→ 数据库模块：查询媒体资源的时间信息
```

**数据流向**：
```
本地媒体同步模块 → List<LocalAsset> → 时间分组转换 → List<TimelineSection> → UI 渲染
```

## 核心组件详解

### 1. TimelineSection 数据模型

表示一个时间段的照片分组，包含该时间段的所有媒体资源。

```dart
/// 分组类型
enum SectionType {
  day,    // 按天分组（最近 3 个月）
  month,  // 按月分组（3 个月到 1 年）
  year,   // 按年分组（1 年以上）
}

/// 时间线分组数据模型
class TimelineSection {
  /// 分组唯一标识（用于缓存和比较）
  /// 格式：day -> "2024-01-15", month -> "2024-01", year -> "2024"
  final String sectionKey;
  
  /// 显示标题（如"今天"、"昨天"、"2024年1月"等）
  final String displayTitle;
  
  /// 该分组的基准时间
  final DateTime dateTime;
  
  /// 该分组下的所有媒体资源
  final List<LocalAsset> assets;
  
  /// 分组类型
  final SectionType sectionType;
  
  /// 该分组在列表中的索引（用于快速定位）
  final int index;
  
  TimelineSection({
    required this.sectionKey,
    required this.displayTitle,
    required this.dateTime,
    required this.assets,
    required this.sectionType,
    required this.index,
  });
}
```

### 2. TimelineGroupingService

负责时间分组算法和标题格式化。

**核心方法**：

1. **groupByTime()**：将 `List<LocalAsset>` 转换为 `List<TimelineSection>`
   - 遍历资产列表，按时间分组
   - 根据时间距离确定分组粒度
   - 生成分组标题

2. **formatSectionTitle()**：格式化分组标题
   - 今天：显示"今天"
   - 昨天：显示"昨天"
   - 本周：显示"本周一"、"本周二"等
   - 本月：显示"1月15日"
   - 跨月：显示"2024年1月"
   - 跨年：显示"2024年"

3. **determineSectionType()**：确定分组类型
   - 根据当前时间和资产时间计算时间差
   - 返回对应的 `SectionType`

**分组粒度规则**：
- **最近 3 个月**：按天分组（`SectionType.day`）
- **3 个月到 1 年**：按月分组（`SectionType.month`）
- **1 年以上**：按年分组（`SectionType.year`）

### 3. timelineSectionsProvider

Riverpod Provider，负责将原始数据转换为分组数据。

```dart
@riverpod
Future<List<TimelineSection>> timelineSections(
  TimelineSectionsRef ref,
) async {
  // 1. 获取原始数据
  final assets = await ref.watch(timelineAssetsProvider().future);
  
  // 2. 执行分组转换
  final groupingService = TimelineGroupingService();
  final sections = groupingService.groupByTime(assets);
  
  return sections;
}
```

### 4. TimelineSliverListBuilder

时间线分组列表构建器，用于构建分组的 Sliver 列表。

**核心特性**：
- 返回 `List<Widget>`，每个 Widget 是一个 Sliver
- 每个分组包含：`SliverToBoxAdapter`（标题）+ `MediaGridSliver`（网格）
- 在 `CustomScrollView` 中使用展开操作符组合多个 Sliver
- 避免嵌套滚动问题，保持虚拟滚动性能

**实现说明**：
- 使用构建器模式而非直接返回单个 Widget
- 每个分组生成两个 Sliver：标题 Sliver 和网格 Sliver
- 通过展开操作符在 `CustomScrollView` 中组合，避免嵌套滚动视图

### 5. TimelineSectionHeader

分组标题组件，显示时间段信息。

**显示内容**：
- 分组标题（如"今天"、"2024年1月"）
- 可选：该分组的照片数量
- 可选：展开/折叠按钮（未来功能）

## 时间分组策略

### 分组粒度规则

根据照片的创建时间与当前时间的距离，采用不同的分组粒度：

| 时间距离 | 分组粒度 | SectionType | 示例 |
|---------|---------|-------------|------|
| 0-3 个月 | 按天 | `day` | "今天"、"昨天"、"1月15日" |
| 3 个月-1 年 | 按月 | `month` | "2024年1月"、"2023年12月" |
| 1 年以上 | 按年 | `year` | "2024年"、"2023年" |

### 分组算法

```dart
List<TimelineSection> groupByTime(List<LocalAsset> assets) {
  final now = DateTime.now();
  final sections = <String, List<LocalAsset>>{};
  
  for (final asset in assets) {
    final createdAt = asset.createdAt;
    final timeDiff = now.difference(createdAt);
    
    // 确定分组类型
    SectionType sectionType;
    String sectionKey;
    
    if (timeDiff.inDays <= 90) {
      // 最近 3 个月：按天分组
      sectionType = SectionType.day;
      sectionKey = '${createdAt.year}-${createdAt.month.toString().padLeft(2, '0')}-${createdAt.day.toString().padLeft(2, '0')}';
    } else if (timeDiff.inDays <= 365) {
      // 3 个月到 1 年：按月分组
      sectionType = SectionType.month;
      sectionKey = '${createdAt.year}-${createdAt.month.toString().padLeft(2, '0')}';
    } else {
      // 1 年以上：按年分组
      sectionType = SectionType.year;
      sectionKey = '${createdAt.year}';
    }
    
    // 添加到对应分组
    sections.putIfAbsent(sectionKey, () => []).add(asset);
  }
  
  // 转换为 TimelineSection 列表
  final result = <TimelineSection>[];
  int index = 0;
  
  for (final entry in sections.entries) {
    final sectionKey = entry.key;
    final assets = entry.value;
    final firstAsset = assets.first;
    
    result.add(TimelineSection(
      sectionKey: sectionKey,
      displayTitle: formatSectionTitle(firstAsset.createdAt, sectionKey),
      dateTime: firstAsset.createdAt,
      assets: assets,
      sectionType: determineSectionType(sectionKey),
      index: index++,
    ));
  }
  
  // 按时间降序排序（最新的在前）
  result.sort((a, b) => b.dateTime.compareTo(a.dateTime));
  
  return result;
}
```

### 标题格式化规则

```dart
String formatSectionTitle(DateTime dateTime, String sectionKey) {
  final now = DateTime.now();
  final today = DateTime(now.year, now.month, now.day);
  final date = DateTime(dateTime.year, dateTime.month, dateTime.day);
  final daysDiff = today.difference(date).inDays;
  
  // 解析 sectionKey 确定分组类型
  final parts = sectionKey.split('-');
  
  if (parts.length == 3) {
    // 按天分组
    if (daysDiff == 0) {
      return '今天';
    } else if (daysDiff == 1) {
      return '昨天';
    } else if (daysDiff <= 7) {
      // 本周
      final weekday = dateTime.weekday;
      final weekdayNames = ['周一', '周二', '周三', '周四', '周五', '周六', '周日'];
      return '本周${weekdayNames[weekday - 1]}';
    } else if (dateTime.year == now.year) {
      // 今年
      return '${dateTime.month}月${dateTime.day}日';
    } else {
      // 跨年
      return '${dateTime.year}年${dateTime.month}月${dateTime.day}日';
    }
  } else if (parts.length == 2) {
    // 按月分组
    if (dateTime.year == now.year) {
      return '${dateTime.year}年${dateTime.month}月';
    } else {
      return '${dateTime.year}年${dateTime.month}月';
    }
  } else {
    // 按年分组
    return '${dateTime.year}年';
  }
}
```

## 实现细节

### 1. 时区处理

**问题**：不同设备可能使用不同的时区，需要统一处理。

**解决方案**：
- 统一使用 `createdAt` 的时区（通常是本地时区）
- 在分组时，使用 `DateTime` 的年/月/日部分，忽略时区差异
- 确保分组算法的一致性

### 2. 边界处理

**问题**：跨天/跨月/跨年的边界判断。

**解决方案**：
- 使用 `DateTime(year, month, day)` 创建标准化的日期对象
- 在分组时，使用日期的年/月/日部分作为分组键
- 确保同一张照片只属于一个分组

### 3. 排序保证

**问题**：分组后需要保持时间顺序。

**解决方案**：
- 原始数据已经按时间降序排序
- 分组后，对 `List<TimelineSection>` 按 `dateTime` 降序排序
- 每个分组内的 `assets` 保持原有顺序（已排序）

### 4. 空状态处理

**问题**：某些时间段可能没有照片。

**解决方案**：
- 分组算法会自动跳过空时间段
- 如果所有分组都为空，显示"暂无照片"提示
- 与现有实现保持一致

### 5. 性能优化

**问题**：大量数据可能导致分组计算耗时。

**解决方案**：
- 分组计算在 `timelineSectionsProvider` 中异步执行
- 使用 `FutureProvider` 或 `AsyncNotifier` 管理异步状态
- 考虑缓存分组结果（未来优化）

## 性能优化

### 1. 虚拟滚动

**实现**：
- 使用 `SliverList.builder` 实现懒加载
- 只渲染可见区域的分组
- 每个分组内部使用 `MediaGridSliver`（已支持虚拟滚动）

**效果**：
- 即使有数千张照片，也能保持流畅滚动
- 内存占用可控，不会一次性加载所有内容

### 2. 分组缓存

**实现**：
- 在 `timelineSectionsProvider` 中缓存分组结果
- 只有当原始数据变化时才重新计算分组
- 使用 `keepAlive` 保持 Provider 状态

**效果**：
- 避免重复计算分组
- 提升页面切换和刷新的响应速度

### 3. 图片预加载

**实现**：
- 复用现有的 `MediaGridSliver` 预加载机制

- 减少用户等待时间

## 错误处理

### 1. 数据加载失败

**场景**：`timelineAssetsProvider` 返回错误。

**处理**：
- 显示错误提示和重试按钮
- 与现有实现保持一致

### 2. 分组计算失败

**场景**：分组算法执行时出现异常。

**处理**：
- 捕获异常，返回空列表或错误状态
- 记录错误日志，便于排查问题
- 显示友好的错误提示

### 3. 时区问题

**场景**：不同设备时区不一致导致分组错误。

**处理**：
- 统一使用本地时区
- 在分组时标准化日期对象
- 确保分组算法的一致性

### 4. 空数据

**场景**：没有照片或所有照片都被过滤。

**处理**：
- 显示"暂无照片"提示
- 与现有实现保持一致

## 总结

照片时间线展示模块通过在现有数据流上增加分组转换层，使用 `TimelineSliverListBuilder` 构建多个 Sliver（`SliverToBoxAdapter` + `MediaGridSliver`），在 `CustomScrollView` 中通过展开操作符组合，实现分组展示，提供清晰的时间线浏览体验。

**核心要点**：
1. **分组策略**：根据时间距离采用不同粒度（天/月/年）
2. **数据转换**：在 Provider 层进行分组转换，保持数据流清晰
3. **虚拟滚动**：使用 `TimelineSliverListBuilder` 构建多个 Sliver，在 `CustomScrollView` 中通过展开操作符组合，避免嵌套滚动问题
4. **性能优化**：懒加载、缓存、内存管理，所有 Sliver 在同一 `CustomScrollView` 中保持虚拟滚动性能
5. **用户体验**：友好的时间显示、流畅的滚动、快速定位

**实施建议**：
- 分阶段实施，先实现基础功能，再逐步优化
- 充分测试，确保性能和稳定性
- 关注用户体验，持续改进
