## 方案概述

### 重构目标

本次重构旨在优化照片页面的媒体资源选择操作体验，参考 Immich 的媒体资源选择操作 UI，实现能够选择指定媒体资源上传的功能。主要目标包括：

1. **改进选择体验**：从简陋的对话框选择改为直观的网格内多选
2. **简化操作流程**：将选择 → 确认 → 上传的三步流程简化为选择 → 上传的两步流程
3. **增强视觉反馈**：提供清晰的选中状态可视化
4. **提升用户体验**：支持长按进入多选模式、全选/取消全选等便捷操作

### 核心功能

1. **多选模式**：在照片网格中直接选择多个媒体资源
2. **选中状态显示**：清晰的视觉反馈（覆盖层 + 选中标记）
3. **选择控制栏**：顶部显示选中数量，底部提供操作按钮
4. **直接上传**：选择后可直接上传，无需额外确认步骤
5. **批量操作**：支持全选、取消全选等批量操作

### 设计原则

1. **用户体验优先**：参考成熟应用（Immich）的交互模式
2. **渐进式增强**：在现有架构基础上增强，保持向后兼容
3. **性能优化**：大量照片时保持流畅的选择和滚动性能
4. **代码复用**：最大化复用现有组件和服务

## 当前状态分析

### 现有实现

#### 1. 照片页面 (`MainTimelinePage`)

**位置**：`lib/presentation/pages/photos/main_timeline_page.dart`

**功能**：
- 显示时间线分组的照片
- 使用 `TimelineSliverListBuilder` 构建时间线列表

- 点击照片进入媒体查看器

**限制**：
- 不支持多选模式
- 只能通过 AppBar 的"备份照片"按钮进入选择流程

#### 2. 媒体网格组件 (`MediaGridSliver`)

**位置**：`lib/presentation/widgets/media/media_grid_view.dart`

**功能**：
- 以网格形式展示媒体资源
- 支持可见性检测和预加载
- 支持点击查看单个媒体

**限制**：
- 不支持多选模式
- 不支持选中状态显示

#### 3. 选择对话框 (`BackupAssetSelectionDialog`)

**位置**：`lib/presentation/widgets/backup/backup_asset_selection_dialog.dart`

**功能**：
- 显示资产列表供用户选择
- 使用 `CheckboxListTile` 展示选择项
- 支持全选/取消全选

**问题**：
- UI 简陋，体验不佳
- 使用列表而非网格，不符合照片浏览习惯
- 需要额外确认步骤

#### 4. 上传流程 (`BackupActionSheet`)

**位置**：`lib/presentation/widgets/backup/backup_action_sheet.dart`

**功能**：
- 显示备份进度和结果
- 调用 `BackupService.startManualBackup` 启动上传

**流程**：
1. 用户点击"备份照片"按钮
2. 弹出 `BackupAssetSelectionDialog` 选择照片
3. 确认后显示 `BackupActionSheet` 开始上传

### 存在的问题

1. **选择体验差**：使用对话框 + 列表的方式，不符合照片浏览习惯
2. **操作步骤多**：选择 → 确认 → 上传，需要三步操作
3. **缺少视觉反馈**：选择过程中无法直观看到选中状态
4. **无法批量操作**：不支持在网格中直接选择多个照片
5. **交互不直观**：需要从 AppBar 进入，不够直观

### 数据流设计

```
用户操作
  │
  ├─ 长按照片 → 进入多选模式
  │   └─ AssetSelectionProvider.selectionActive = true
  │
  ├─ 点击照片 → 切换选中状态
  │   └─ AssetSelectionProvider.toggle(assetId)
  │
  ├─ 点击上传 → 获取选中资产 → 调用上传服务
  │   └─ BackupService.startManualBackup(assetIds)
  │
  └─ 点击取消 → 退出多选模式
      └─ AssetSelectionProvider.clear() + selectionActive = false
```

#### 选择状态 Provider

```dart
// lib/providers/selection/asset_selection_provider.dart

/// 资产选择状态
class AssetSelectionState {
  final Set<String> selectedIds;
  final bool isActive;

  const AssetSelectionState({
    this.selectedIds = const {},
    this.isActive = false,
  });

  AssetSelectionState copyWith({
    Set<String>? selectedIds,
    bool? isActive,
  }) {
    return AssetSelectionState(
      selectedIds: selectedIds ?? this.selectedIds,
      isActive: isActive ?? this.isActive,
    );
  }

  int get count => selectedIds.length;
  bool isEmpty() => selectedIds.isEmpty;
  bool isSelected(String assetId) => selectedIds.contains(assetId);
}

/// 资产选择状态管理
class AssetSelectionNotifier extends StateNotifier<AssetSelectionState> {
  AssetSelectionNotifier() : super(const AssetSelectionState());

  /// 进入选择模式
  void activate() {
    state = state.copyWith(isActive: true);
  }

  /// 退出选择模式
  void deactivate() {
    state = state.copyWith(
      isActive: false,
      selectedIds: {},
    );
  }

  /// 切换选中状态
  void toggle(String assetId) {
    final newIds = Set<String>.from(state.selectedIds);
    if (newIds.contains(assetId)) {
      newIds.remove(assetId);
    } else {
      newIds.add(assetId);
    }
    state = state.copyWith(selectedIds: newIds);
  }

  /// 全选
  void selectAll(List<String> assetIds) {
    state = state.copyWith(selectedIds: Set.from(assetIds));
  }

  /// 取消全选
  void clear() {
    state = state.copyWith(selectedIds: {});
  }

  /// 检查是否选中
  bool isSelected(String assetId) {
    return state.selectedIds.contains(assetId);
  }
}

/// Provider 定义
final assetSelectionProvider = 
    StateNotifierProvider<AssetSelectionNotifier, AssetSelectionState>(
  (ref) => AssetSelectionNotifier(),
);
```

```dart
class SelectableMediaGridSliver extends StatefulWidget {
  final List<BaseAsset> assets;
  final bool selectionActive;
  final Set<String> selectedIds;
  final void Function(BaseAsset asset, int index)? onTap;
  final void Function(BaseAsset asset)? onSelectionToggle;
  final int crossAxisCount;
  final double crossAxisSpacing;
  final double mainAxisSpacing;
  final double childAspectRatio;
  final String? serverUrl;
  final int preloadRange;
  final AssetEntityLoader? assetEntityLoader;

  const SelectableMediaGridSliver({
    super.key,
    required this.assets,
    required this.selectionActive,
    required this.selectedIds,
    this.onTap,
    this.onSelectionToggle,
    this.crossAxisCount = 4,
    this.crossAxisSpacing = 2.0,
    this.mainAxisSpacing = 2.0,
    this.childAspectRatio = 1.0,
    this.serverUrl,
    this.preloadRange = 2,
    this.assetEntityLoader,
  });

  @override
  State<SelectableMediaGridSliver> createState() =>
      _SelectableMediaGridSliverState();
}

class _SelectableMediaGridSliverState
    extends State<SelectableMediaGridSliver> {
  @override
  Widget build(BuildContext context) {
    return SliverGrid(
      gridDelegate: SliverGridDelegateWithFixedCrossAxisCount(
        crossAxisCount: widget.crossAxisCount,
        crossAxisSpacing: widget.crossAxisSpacing,
        mainAxisSpacing: widget.mainAxisSpacing,
        childAspectRatio: widget.childAspectRatio,
      ),
      delegate: SliverChildBuilderDelegate(
        (context, index) {
          final asset = widget.assets[index];
          final isSelected = widget.selectedIds.contains(asset.id);

          return SelectableMediaItem(
            asset: asset,
            isSelected: isSelected,
            selectionActive: widget.selectionActive,
            onTap: widget.selectionActive
                ? () => widget.onSelectionToggle?.call(asset)
                : () => widget.onTap?.call(asset, index),
            serverUrl: widget.serverUrl,
            assetEntityLoader: widget.assetEntityLoader,
          );
        },
        childCount: widget.assets.length,
      ),
    );
  }
}
```

```dart
// lib/presentation/widgets/timeline/selectable_timeline_sliver_list.dart

class SelectableTimelineSliverListBuilder {
  final List<TimelineSection> sections;
  final bool selectionActive;
  final Set<String> selectedIds;
  final void Function(BaseAsset asset, int index)? onTap;
  final void Function(BaseAsset asset)? onSelectionToggle;
  final int crossAxisCount;
  final double crossAxisSpacing;
  final double mainAxisSpacing;
  final double childAspectRatio;
  final String? serverUrl;
  final int preloadRange;
  final AssetEntityLoader? assetEntityLoader;

  const SelectableTimelineSliverListBuilder({
    required this.sections,
    required this.selectionActive,
    required this.selectedIds,
    this.onTap,
    this.onSelectionToggle,
    this.crossAxisCount = 5,
    this.crossAxisSpacing = 2.0,
    this.mainAxisSpacing = 2.0,
    this.childAspectRatio = 1.0,
    this.serverUrl,
    this.preloadRange = 2,
    this.assetEntityLoader,
  });

  List<Widget> build() {
    if (sections.isEmpty) {
      return [const SliverToBoxAdapter(child: SizedBox.shrink())];
    }

    final slivers = <Widget>[];

    for (final section in sections) {
      // 添加分组标题
      slivers.add(
        SliverToBoxAdapter(
          child: TimelineSectionHeader(
            section: section,
            showAssetCount: true,
          ),
        ),
      );

      // 添加可选择的媒体网格
      slivers.add(
        SliverPadding(
          padding: const EdgeInsets.symmetric(horizontal: 2),
          sliver: SelectableMediaGridSliver(
            assets: section.assets,
            selectionActive: selectionActive,
            selectedIds: selectedIds,
            onTap: onTap,
            onSelectionToggle: onSelectionToggle,
            crossAxisCount: crossAxisCount,
            crossAxisSpacing: crossAxisSpacing,
            mainAxisSpacing: mainAxisSpacing,
            childAspectRatio: childAspectRatio,
            serverUrl: serverUrl,
            preloadRange: preloadRange,
            assetEntityLoader: assetEntityLoader,
          ),
        ),
      );
    }

    return slivers;
  }
}
```

#### 1. 进入多选模式

**方式一：长按照片**
- 用户长按任意照片
- 进入多选模式，该照片自动选中
- 显示选择控制栏

- 用户点击 AppBar 的"选择"按钮
- 进入多选模式
- 显示选择控制栏

- 点击照片：切换选中状态
- 选中状态：显示蓝色半透明覆盖层 + 右上角选中标记

- **全选**：选中当前可见的所有照片
- **取消全选**：取消所有选中状态
- **上传**：上传选中的照片

#### 4. 退出多选模式

- 点击顶部栏的关闭按钮
- 或点击底部栏的取消按钮
- 清空选中状态，恢复正常浏览模式

```dart
// 在选择控制栏中
void _handleUpload() async {
  final selectionState = ref.read(assetSelectionProvider);
  if (selectionState.selectedIds.isEmpty) return;

  try {
    // 获取用户ID
    final authService = await ref.read(authServiceProvider.future);
    final profile = await authService.getProfile();
    final userId = profile.id.toString();

    // 获取备份服务
    final backupService = await ref.read(backupServiceProvider.future);

    // 启动上传
    await backupService.startManualBackup(
      userId: userId,
      assetIds: selectionState.selectedIds.toList(),
      skipDeduplication: false,
    );

    // 显示成功提示
    if (mounted) {
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(
          content: Text('已开始上传 ${selectionState.selectedIds.length} 张照片'),
          duration: const Duration(seconds: 2),
        ),
      );

      // 退出选择模式
      ref.read(assetSelectionProvider.notifier).deactivate();
    }
  } catch (e) {
    // 显示错误提示
    if (mounted) {
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(
          content: Text('上传失败: $e'),
          backgroundColor: Colors.red,
          duration: const Duration(seconds: 3),
        ),
      );
    }
  }
}
```
