# Issues 目录

本目录用于记录项目中发现的问题、待修复的功能缺陷以及技术债务。

## 目录说明

- 每个issue使用独立的Markdown文件记录
- 文件命名格式：`问题描述.md` 或 `功能名称-问题描述.md`
- 每个issue文档应包含：
  - 问题描述
  - 当前实现分析
  - 需要实现的功能
  - 实施步骤
  - 技术细节
  - 优先级
  - 相关文件

## 状态说明

- **待修复** - 已记录但尚未开始修复
- **进行中** - 正在修复中
- **已完成** - 已修复并验证
- **已关闭** - 不再需要修复（如已废弃功能）
