# Immich 移动端架构参考文档

> 本文档目录包含了对 Immich 移动端架构的详细剖析文档，涵盖系统架构、核心模块、功能实现等多个方面，可作为相册应用开发的重要参考。

## 📚 文档导航

### 🏗️ 系统架构文档

这些文档从系统层面阐述了 Immich 移动端的整体架构设计：

| 文档 | 说明 |
|------|------|
| [API 对接架构](./API_ARCHITECTURE.md) | 详细说明移动端如何与服务器 API 对接，包括认证机制、HTTP/HTTPS 支持、错误处理、重试机制等 |
| [数据库架构](./DATABASE_ARCHITECTURE.md) | 介绍 Drift (SQLite) 数据库的设计，包括表结构、关系设计、索引策略、数据迁移方案等 |
| [媒体加载架构](./MEDIA_LOADING_ARCHITECTURE.md) | 阐述多级渐进式媒体加载架构，包括资源选择、分级加载、缓存机制、占位符优化等 |
| [页面架构](./PAGE_ARCHITECTURE.md) | 说明单导航容器架构（TabShell）设计，包括导航系统、核心页面、查看器页面、交互设计等 |
| [后台备份架构](./BACKGROUND_BACKUP_ARCHITECTURE.md) | 介绍基于独立 Flutter Engine 的后台备份方案，包括任务调度、同步机制、资源管理等 |
| [后台备份实施指南](./BACKGROUND_BACKUP_IMPLEMENTATION_GUIDE.md) | 后台备份功能的详细实施指南 |

## 📖 阅读建议

### 按学习路径阅读

1. **入门阶段**：先阅读系统架构文档，了解整体架构
   - 从 [移动端架构总览](./架构详解/mobile-architecture-detail.md) 开始
   - 然后阅读 [API 对接架构](./API_ARCHITECTURE.md) 和 [数据库架构](./DATABASE_ARCHITECTURE.md)

2. **深入阶段**：按功能模块深入理解
   - 核心功能：资产模块 → 相册模块 → 时间线模块
   - 同步功能：备份模块 → 同步下载模块
   - 高级功能：搜索模块 → 地图模块 → 人物模块

3. **优化阶段**：关注性能和用户体验
   - 媒体加载架构 → 图片缓存模块
   - 页面架构 → 设置配置模块

### 按开发需求阅读

- **开发 API 对接**：API 对接架构 + HTTPS 模块 + 基础服务模块
- **开发数据层**：数据库架构 + 相关模块的 Repository 实现
- **开发 UI 层**：页面架构 + 相关功能模块的 UI 实现
- **开发后台功能**：后台备份架构 + 备份模块 + 同步下载模块
- **优化性能**：媒体加载架构 + 图片缓存模块
