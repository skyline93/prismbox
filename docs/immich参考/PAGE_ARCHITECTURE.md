## 架构概述

Immich 移动端采用**单导航容器架构**（TabShell），通过统一的底部导航栏（竖屏）或侧边导航栏（横屏）管理四个核心页面，实现了清晰的信息架构和流畅的用户体验。

### 核心特点

- **统一导航容器**：TabShell 作为唯一的导航容器，管理所有主要页面
- **响应式布局**：自动适配竖屏/横屏，切换导航栏位置
- **状态隔离**：每个标签页独立维护状态，切换时按需刷新
- **只读模式支持**：支持禁用部分功能，适配特殊场景
- **流畅动画**：标签切换使用淡入淡出动画（600ms）
- **智能刷新**：标签切换时自动刷新相关数据

## 导航架构设计

### 2.1 TabShell 容器设计

**功能定位**：应用的主导航容器，管理四个核心标签页

**设计要点**：

#### 2.1.1 容器结构
- **路由配置**：使用 AutoRoute 的 CustomRoute 包装，包含四个子路由
- **标签页路由**：
  - `MainTimelineRoute`：照片时间线页面
  - `DriftSearchRoute`：搜索页面
  - `DriftAlbumsRoute`：相册页面
  - `DriftLibraryRoute`：资料库页面
- **过渡动画**：使用 `TransitionsBuilders.fadeIn`，600ms 淡入淡出

#### 2.1.2 导航栏设计
- **竖屏模式**：底部 `NavigationBar`
  - 4 个导航目标（NavigationDestination）
  - 选中状态显示填充图标 + 主题色
  - 未选中状态显示轮廓图标
  - 支持禁用状态（只读模式）
- **横屏模式**：左侧 `NavigationRail`
  - 垂直排列的导航目标
  - 显示标签文本
  - 右侧显示分隔线和内容区域

#### 2.1.3 导航交互逻辑
- **标签切换行为**：
  - Photos 标签：点击已激活的 Photos 标签时，滚动到顶部
  - Search 标签：点击已激活的 Search 标签时，聚焦搜索输入框
  - Albums 标签：切换到 Albums 时，自动刷新远程相册列表
  - Library 标签：切换到 Library 时，刷新本地相册和人物数据
- **返回行为**：使用 `PopScope`，只有在 Photos 标签时才能返回退出应用
- **多选模式**：多选模式启用时，自动隐藏底部导航栏

#### 2.1.4 只读模式支持
- 检测只读模式状态
- 禁用 Search、Albums、Library 标签（保留 Photos 标签可用）
- 导航目标显示禁用状态

### 2.2 路由守卫系统

**功能定位**：控制页面访问权限和导航流程

**守卫类型**：

1. **AuthGuard（认证守卫）**
   - 检查用户是否已登录
   - 未登录时重定向到登录页面
   - 所有主要页面都需要此守卫

2. **DuplicateGuard（重复导航守卫）**
   - 防止重复导航到同一页面
   - 避免导航栈混乱

3. **GalleryGuard（图库权限守卫）**
   - 检查图库访问权限
   - 用于图库查看器页面

4. **BackupPermissionGuard（备份权限守卫）**
   - 检查备份相关权限
   - 用于备份功能页面

5. **LockedGuard（锁定守卫）**
   - 检查锁定视图状态
   - 用于锁定文件夹访问

### 2.3 页面路由配置

**路由层次结构**：

```
AppRouter (根路由)
├── SplashScreenRoute (初始页面)
├── PermissionOnboardingRoute (权限引导)
├── LoginRoute (登录页面)
├── TabShellRoute (主导航容器)
│   ├── MainTimelineRoute (照片时间线)
│   ├── DriftSearchRoute (搜索)
│   ├── DriftAlbumsRoute (相册)
│   └── DriftLibraryRoute (资料库)
├── GalleryViewerRoute (图库查看器)
├── AssetViewerRoute (资产查看器)
├── AlbumViewerRoute (相册查看器)
├── SettingsRoute (设置)
└── ... (其他功能页面)
```

**路由特性**：
- 使用 `maintainState: false` 控制页面状态保持（搜索页面不保持状态）
- 自定义过渡动画（缩放、侧滑、淡入等）
- 路由参数传递（相册ID、资产索引等）

## 核心页面设计

### 3.1 Photos 页面（MainTimelinePage）

**功能定位**：主时间线，展示所有照片和视频的时间线视图

**设计要点**：

#### 3.1.1 页面结构
- **顶部组件**：Memory Lane（记忆通道）
  - 条件显示：仅在启用记忆功能且有记忆数据时显示
  - 高度：200px（有记忆时）/ 0（无记忆时）
  - 展示最近的重要记忆
- **主内容区**：Timeline Widget
  - 使用 CustomScrollView + Sliver 架构
  - 支持虚拟滚动，性能优化
  - 显示存储指示器

#### 3.1.2 Timeline Widget 设计
- **Sliver 架构**：
  - `ImmichSliverAppBar`：浮动式应用栏
  - `SliverGrid`：时间线网格
  - `Scrubber`：时间轴滚动条（可选）
  - `GeneralBottomSheet`：底部操作表单
- **分组策略**：
  - 按日期分组（默认）
  - 支持按月份快照
  - 显示日期标题
- **网格配置**：
  - 可配置每行显示数量（设置中配置）
  - 响应式布局，适配不同屏幕
  - 支持堆叠显示（Stack）

#### 3.1.3 交互功能
- **滚动行为**：
  - 支持快速滚动
  - 时间轴滚动条显示当前位置
  - 支持滚动到顶部事件
- **多选模式**：
  - 长按进入多选模式
  - 拖拽选择多个资产
  - 多选时隐藏导航栏
- **点击行为**：
  - 点击资产进入查看器
  - Hero 动画过渡
  - 传递资产索引和列表信息

#### 3.1.4 状态管理
- 使用 Riverpod 管理时间线数据
- 按需加载时间线段（Timeline Segment）
- 支持增量加载和刷新

### 3.2 Search 页面（DriftSearchPage）

**功能定位**：多维度智能搜索照片和视频

**设计要点**：

#### 3.2.1 页面结构
- **顶部搜索栏**：
  - 使用 `ImmichSliverAppBar` 集成搜索框
  - 支持 4 种搜索模式切换（上下文、文件名、描述、OCR）
  - 动态图标和提示文本
  - 渐变背景样式
- **筛选器芯片栏**：
  - 水平滚动的筛选器列表
  - 6 个筛选维度：人物、位置、相机、日期、媒体类型、显示选项
  - 选中状态可视化显示
- **搜索结果区**：
  - 使用 Timeline Widget 展示结果
  - 分页加载机制
  - 空状态展示快速链接

#### 3.2.2 搜索功能设计
- **文本搜索类型**：
  - 上下文搜索：基于 AI 理解的语义搜索
  - 文件名搜索：精确匹配文件名
  - 描述搜索：搜索照片描述
  - OCR 搜索：识别照片中的文字
- **筛选器设计**：
  - **人物筛选器**：
    - 底部表单选择器
    - 显示人物头像网格
    - 支持多选
    - 显示已选人物名称
  - **位置筛选器**：
    - 三级选择：国家 → 州/省 → 城市
    - 地图可视化（可选）
    - 显示已选位置层级
  - **相机筛选器**：
    - 品牌和型号选择
    - 显示已选相机信息
  - **日期筛选器**：
    - 日期范围选择器
    - 支持单日或日期区间
    - 显示格式化日期范围
  - **媒体类型筛选器**：
    - 图片/视频/全部
    - 单选模式
  - **显示选项筛选器**：
    - 不在相册中
    - 已归档
    - 收藏
    - 多选模式

#### 3.2.3 搜索交互
- **搜索触发**：
  - 文本输入后自动搜索（防抖）
  - 筛选器变更后自动搜索
  - 支持手动触发搜索
- **结果展示**：
  - 使用分页加载
  - 滚动到底部自动加载更多
  - 显示加载状态
  - 无结果时显示提示和快速链接
- **快速链接**：
  - 最近拍摄
  - 所有视频
  - 收藏

#### 3.2.4 状态管理
- 使用 `paginatedSearchProvider` 管理搜索结果
- 筛选器状态本地管理
- 支持预筛选（从其他页面跳转时携带筛选条件）

### 3.3 Albums 页面（DriftAlbumsRoute）

**功能定位**：管理远程相册集合

**设计要点**：

#### 3.3.1 页面结构
- **顶部应用栏**：
  - 显示标题
  - 创建相册按钮
  - 支持下拉刷新
- **搜索和筛选区**：
  - 搜索框（支持渐变背景）
  - 快速筛选按钮（全部/与我共享/我的相册）
- **排序和视图切换**：
  - 排序按钮（菜单式选择器）
  - 视图切换按钮（网格/列表）
- **相册列表/网格**：
  - 根据视图模式显示
  - 支持下拉刷新

#### 3.3.2 相册展示设计
- **网格视图**：
  - 卡片式展示
  - 显示相册缩略图
  - 显示相册名称
  - 显示所有者信息（如果是共享相册）
  - 显示资产数量
- **列表视图**：
  - 大缩略图（80x80）
  - 标题和副标题
  - 显示元数据（数量、所有者）
  - 更紧凑的布局

#### 3.3.3 搜索和筛选
- **搜索功能**：
  - 实时搜索（300ms 防抖）
  - 搜索相册名称
  - 支持清除搜索
- **快速筛选**：
  - 全部：显示所有相册
  - 与我共享：显示共享给我的相册
  - 我的相册：显示我创建的相册
- **排序功能**：
  - 按名称排序
  - 按日期排序
  - 按资产数量排序
  - 支持升序/降序切换

#### 3.3.4 交互设计
- **点击相册**：进入相册查看器
- **长按相册**：显示上下文菜单（编辑、删除等）
- **下拉刷新**：刷新相册列表
- **创建相册**：跳转到创建相册页面

### 3.4 Library 页面（DriftLibraryPage）

**功能定位**：快速访问各种收藏和集合

**设计要点**：

#### 3.4.1 页面结构
- **顶部应用栏**：`ImmichSliverAppBar`
- **操作按钮网格**（2x2）：
  - 收藏按钮
  - 归档按钮
  - 共享链接按钮
  - 回收站按钮（需服务器支持）
- **集合卡片**（横向排列）：
  - 人物集合卡片
  - 地点集合卡片
  - 本地相册卡片
- **快速访问列表**：
  - 文件夹
  - 锁定文件夹
  - 合作伙伴
  - 合作伙伴详情列表

#### 3.4.2 操作按钮设计
- **按钮样式**：
  - 填充按钮样式
  - 图标 + 标签
  - 主题色图标
  - 半透明背景容器
- **按钮布局**：
  - 2x2 网格布局
  - 响应式间距
  - 根据功能可用性动态显示

#### 3.4.3 集合卡片设计
- **人物集合卡片**：
  - 显示前 4 个人物头像（2x2 网格）
  - 渐变背景
  - 点击进入人物集合页面
  - 显示"人物"标签
- **地点集合卡片**：
  - 地图缩略图展示
  - 使用 MapLibre GL 渲染
  - 显示"地点"标签
  - 点击进入地点集合页面
- **本地相册卡片**：
  - 显示前 4 个本地相册缩略图
  - 渐变背景
  - 显示"在此设备上"标签
  - 点击进入本地相册列表

#### 3.4.4 快速访问列表
- **容器设计**：
  - 渐变背景容器
  - 圆角边框
  - 列表项样式
- **列表项**：
  - 文件夹：浏览文件夹结构
  - 锁定文件夹：需要 PIN 验证
  - 合作伙伴：显示共享用户列表
  - 合作伙伴详情：动态列表，显示每个合作伙伴

#### 3.4.5 响应式布局
- 集合卡片宽度：
  - 手机：屏幕宽度的 50% - 间距
  - 平板：屏幕宽度的 25% - 间距
- 自适应间距和边距

  - 描述信息
  - 共享信息
- **交互**：上滑关闭，支持拖拽

#### 4.1.6 沉浸式体验
- **全屏模式**：
  - 隐藏系统 UI（状态栏、导航栏）
  - 缩放时自动进入全屏
  - 显示控制栏时恢复系统 UI
- **手势交互**：

  - 上下滑动关闭（可选）
  - 双击缩放
  - 长按显示菜单

## 总结

Immich 移动端页面架构采用**单导航容器（TabShell）**设计，通过统一的导航栏管理四个核心页面，实现了清晰的信息架构和流畅的用户体验。架构设计注重：

1. **清晰的导航结构**：单容器管理，避免导航混乱
2. **响应式设计**：适配不同屏幕尺寸和方向
3. **流畅的交互**：合理的动画和手势支持
4. **性能优化**：虚拟滚动、懒加载、缓存策略
5. **可维护性**：组件化设计、清晰的状态管理

该架构设计可以作为其他相册应用开发的参考，提供了完整的页面设计思路和实现方案。
