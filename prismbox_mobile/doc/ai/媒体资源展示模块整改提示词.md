### 1. 可取消加载机制实现

```dart
// lib/features/media_loading/mixins/cancellable_image_provider_mixin.dart
mixin CancellableImageProviderMixin<T extends ImageProvider<T>> on ImageProvider<T> {
  bool _isCancelled = false;
  ImageRequest? _currentRequest;
  StreamSubscription? _subscription;
  
  bool get isCancelled => _isCancelled;
  
  void cancel() {
    _isCancelled = true;
    _currentRequest?.cancel();
    _subscription?.cancel();
    _currentRequest = null;
    _subscription = null;
  }
  
  // 在 loadImage 中检查取消状态
  // 在加载过程中定期检查 _isCancelled
}
```

// lib/features/media_loading/exceptions/network_image_exception.dart
class NetworkImageException implements Exception {
  final String message;

  final String? url;
  
  NetworkImageException({
    required this.message,
    this.statusCode,
    this.url,
  });
  
  @override
  String toString() => 'NetworkImageException: $message (statusCode: $statusCode, url: $url)';
}

// 在 RemoteImageRequest 中使用
try {
  return await _loadFromNetwork();
} on NetworkImageException catch (e) {
  // 回退到缓存
  final cached = await _loadFromCache();
  if (cached != null) return cached;
  rethrow;
}
```

// lib/features/media_loading/providers/local_full_provider.dart
Stream<ui.Codec> _loadImage(...) async* {
  // 阶段 1：加载缩略图
  final thumbCodec = await _loadThumbnail(...);
  yield thumbCodec;
  
  // 阶段 2：加载适配分辨率图片
  final adaptedCodec = await _loadAdaptedImage(...);
  yield adaptedCodec;
  
  // 阶段 3：根据设置决定是否加载原图
  final shouldLoadOriginal = AppSetting.get(Setting.loadOriginal);
  if (shouldLoadOriginal) {
    final originalCodec = await _loadOriginalImage(...);
    yield originalCodec;
  }
}
```

2. **文件路径列表**：列出所有创建和修改的文件及其完整路径
3. **测试说明**：说明如何测试修复的功能
4. **注意事项**：列出需要注意的问题
5. **后续工作**：列出需要完善的功能

## 开始整改

当收到整改请求时，请：

1. **确认任务**：确认要整改的任务（可以指定具体任务编号）
2. **阅读文档**：仔细阅读问题记录文档和设计文档的相关章节
3. **理解需求**：理解问题的具体描述、影响和修复要求
4. **设计实现**：设计实现方案，确定需要创建和修改的文件
5. **实现代码**：按照要求实现代码，确保文件路径正确
6. **验证代码**：检查代码是否符合要求，路径是否正确
7. **提供说明**：提供修复说明、文件路径列表和测试说明
