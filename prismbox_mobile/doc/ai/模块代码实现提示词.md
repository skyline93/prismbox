## 项目背景

PrismBox 是一个全新的高性能相册应用，采用分层架构和模块化设计。项目使用以下核心技术栈：

- **框架**：Flutter 3.x+
- **状态管理**：Riverpod 2.x
- **路由**：AutoRoute 8.x
- **数据库**：Drift (SQLite) 2.x
- **网络**：Dio 5.x、background_downloader 9.x
- **本地资源**：photo_manager 3.x
- **缓存**：flutter_cache_manager 3.x
- **跨平台通信**：Pigeon

### 示例 2：实现 API 服务

根据 `API对接模块详细设计文档.md` 实现 API 服务：

**文件路径**：`prismbox_mobile/lib/infrastructure/api/api_service.dart`

```dart
// lib/infrastructure/api/api_service.dart
import 'package:dio/dio.dart';
import 'package:prismbox/core/storage/secure_storage_service.dart';
import 'package:prismbox/infrastructure/api/interceptors/auth_interceptor.dart';
import 'package:prismbox/infrastructure/api/interceptors/error_interceptor.dart';

class ApiService {
  final Dio _dio;
  final SecureStorageService _secureStorage;
  
  ApiService({
    required Dio dio,
    required SecureStorageService secureStorage,
  })  : _dio = dio,
        _secureStorage = secureStorage {
    // 配置拦截器
    _dio.interceptors.add(AuthInterceptor(_secureStorage));
    _dio.interceptors.add(ErrorInterceptor());
  }
  
  // 实现 API 方法
  Future<UserDto> getCurrentUser() async {
    try {
      final response = await _dio.get('/user/me');
      return UserDto.fromJson(response.data);
    } catch (e) {
      throw ApiException.fromError(e);
    }
  }
}
```

### 示例 3：实现 Riverpod Provider

**文件路径**：`prismbox_mobile/lib/providers/services/backup_service_provider.dart`

```dart
// lib/providers/services/backup_service_provider.dart
import 'package:riverpod_annotation/riverpod_annotation.dart';
import 'package:prismbox/data/database/app_database.dart';
import 'package:prismbox/infrastructure/api/api_service.dart';
import 'package:prismbox/services/backup/backup_service.dart';
import 'package:prismbox/providers/infrastructure/database_provider.dart';
import 'package:prismbox/providers/infrastructure/api_service_provider.dart';

part '../../../prismbox_mobile.bak/doc/ai/backup_service_provider.g.dart';

@riverpod
BackupService backupService(BackupServiceRef ref) {
  final database = ref.watch(databaseProvider);
  final apiService = ref.watch(apiServiceProvider);
  return BackupService(
    database: database,
    apiService: apiService,
  );
}
```

## 常见问题和注意事项

### 1. 项目路径
- **所有代码文件必须放在 `prismbox_mobile/lib/` 目录下**
- 文件路径必须遵循架构文档中定义的目录结构
- 导入路径使用相对路径或从 `lib` 目录开始的绝对路径

### 2. 依赖注入
- 使用 Riverpod 进行依赖注入
- 避免直接创建依赖，通过 Provider 获取
- 使用 `ref.watch()` 监听依赖变化
- 使用 `ref.read()` 一次性获取依赖

### 3. 异步操作
- 使用 `async/await` 处理异步操作
- 使用 `Future` 和 `Stream` 处理异步数据
- 避免在 `build` 方法中直接调用异步操作
- 使用 `FutureBuilder` 或 `StreamBuilder` 处理异步数据

### 4. 状态管理
- 使用 Riverpod Provider 管理状态
- 避免在 Widget 中直接管理复杂状态
- 使用 `Consumer` 或 `HookConsumerWidget` 监听状态变化
- 及时释放不再使用的 Provider

### 5. 错误处理
- 所有可能失败的操作都要处理错误
- 提供友好的错误提示
- 记录错误日志
- 实现错误恢复机制

### 6. 性能优化
- 使用 `const` 构造函数
- 避免不必要的重建
- 使用虚拟滚动（`ListView.builder`）
- 及时释放资源
- 使用 `isolate` 处理耗时操作
