### 任务 3：优化设备分辨率获取 ⚠️ **低优先级（可选优化）**

#### 任务描述

优化 `LocalFullImageProvider._getDeviceResolution()` 方法，根据实际设备分辨率动态获取，而不是使用固定值。

#### 文件位置

- **主要文件**: `lib/features/media_loading/providers/local_full_provider.dart`
- **相关文件**: `lib/features/media_loading/image_provider_factory.dart`

#### 当前问题

```dart
// lib/features/media_loading/providers/local_full_provider.dart:245-251
Size _getDeviceResolution() {
  // 默认使用 1080p 分辨率
  // 实际应用中可以通过 MediaQuery 获取，但这里没有 BuildContext
  // 所以使用合理的默认值
  return const Size(1080, 1920);
}
```

#### 实施步骤

**步骤 1：选择实施方案**

推荐使用**方案 3：使用 window.physicalSize（最简单）**：

```dart
import 'dart:ui' as ui;

Size _getDeviceResolution() {
  try {
    // 使用 Flutter 的 window API
    final views = ui.PlatformDispatcher.instance.views;
    if (views.isNotEmpty) {
      final view = views.first;
      final physicalSize = view.physicalSize;
      final devicePixelRatio = view.devicePixelRatio;
      return Size(
        physicalSize.width / devicePixelRatio,
        physicalSize.height / devicePixelRatio,
      );
    }
  } catch (e) {
    // 如果获取失败，使用默认值
  }
  return const Size(1080, 1920);  // 回退值
}
```

**步骤 2：实现设备分辨率获取**

更新 `LocalFullImageProvider._getDeviceResolution()` 方法：

```dart
// lib/features/media_loading/providers/local_full_provider.dart
import 'dart:ui' as ui;

Size _getDeviceResolution() {
  try {
    final views = ui.PlatformDispatcher.instance.views;
    if (views.isNotEmpty) {
      final view = views.first;
      final physicalSize = view.physicalSize;
      final devicePixelRatio = view.devicePixelRatio;
      
      // 计算逻辑分辨率（考虑设备像素比）
      return Size(
        physicalSize.width / devicePixelRatio,
        physicalSize.height / devicePixelRatio,
      );
    }
  } catch (e) {
    _log.warning('Failed to get device resolution, using default', e);
  }
  
  // 回退到默认值
  return const Size(1080, 1920);
}
```
