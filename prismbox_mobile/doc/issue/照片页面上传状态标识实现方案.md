## 概述

本文档详细说明了在照片页面缩略图右上角显示上传状态标识的完整实现方案。该功能让用户能够快速识别哪些照片已备份到服务器，哪些还未备份。

**功能目标**：
- 在照片页面每个缩略图右上角显示上传状态图标
- 已上传照片显示云朵完成图标（✓）
- 未上传照片显示云朵关闭图标（✗）
- 不影响现有功能（选中标记、视频标识、收藏标记等）

**前置条件**：
- ✅ 必须先修复 `本地和远程资源表未充分利用问题分析.md` 中描述的问题
- ✅ 确保上传成功后 `LocalAsset.remoteAssetId` 被正确设置
- ✅ 确保 `BaseAsset.hasRemote` 能正确判断上传状态

## 一、实现可行性分析

### 1.1 数据流分析

**当前数据流**：
```
上传成功
  ↓
❌ 未更新 LocalAsset.remoteAssetId
  ↓
TimelineProviderService 查询数据库
  ↓
❌ remoteAssetId 为 null
  ↓
LocalAsset.storage = AssetState.local
  ↓
BaseAsset.hasRemote = false
  ↓
❌ 无法显示上传状态
```

**修复后的数据流**：
```
上传成功
  ↓
✅ 更新 LocalAsset.remoteAssetId（修复数据库问题后）
  ↓
TimelineProviderService 查询数据库
  ↓
✅ remoteAssetId 不为 null
  ↓
LocalAsset.storage = AssetState.merged
  ↓
BaseAsset.hasRemote = true
  ↓
✅ 可以显示上传状态
```

### 1.2 判断逻辑

**状态判断依据**：
- `BaseAsset.hasRemote` 属性：`storage == AssetState.remote || storage == AssetState.merged`
- `LocalAsset.storage` 实现：`remoteId == null ? AssetState.local : AssetState.merged`
- `LocalAsset.remoteId` 来源：`remoteAssetId` 字段

**判断逻辑**：
```dart
// LocalAsset.storage 实现
@override
AssetState get storage => remoteId == null ? AssetState.local : AssetState.merged;

// BaseAsset.hasRemote 实现
bool get hasRemote => storage == AssetState.remote || storage == AssetState.merged;

// 因此：
// - 如果 remoteAssetId != null → storage = merged → hasRemote = true ✅ 已上传
// - 如果 remoteAssetId == null → storage = local → hasRemote = false ❌ 未上传
```

**结论**：
✅ **修复数据库问题后，上传状态标识功能可以正常工作**

```dart
class _StorageIcon extends StatelessWidget {
```

### 3.3 处理边界情况

#### 3.3.1 视频缩略图

**问题**：视频缩略图右上角已有视频时长标识

**解决方案**：
- 上传状态图标放在视频时长标识上方
- 如果存在视频时长标识，上传状态图标距离上边缘 8px
- 视频时长标识距离上边缘 28px（上传状态图标下方）

**实现**：
```dart
class _UploadStatusIcon extends StatelessWidget {
  final BaseAsset asset;
  final bool hasVideoDuration; // 是否显示视频时长
  
  const _UploadStatusIcon({
    required this.asset,
    this.hasVideoDuration = false,
  });
  
  @override
  Widget build(BuildContext context) {
    final isUploaded = asset.hasRemote;
    
    // 如果存在视频时长标识，上传状态图标放在其上方
    final top = hasVideoDuration ? 8.0 : 8.0; // 可以根据需要调整
```
