# 数据源阈值配置说明

**创建时间**: 2025-12-11  
**相关文件**: 
- `lib/core/storage/store_key.dart`
- `lib/core/settings/app_setting.dart`
- `lib/features/local_sync/services/data_source_selector.dart`

## 概述

数据源阈值用于决定何时从 `photo_manager` 数据源切换到数据库数据源。当数据库中的媒体资产数量达到阈值时，系统会自动切换到数据库数据源，以获得更好的查询性能。

## 配置位置

### 1. 配置键定义

**文件**: `lib/core/storage/store_key.dart`

```dart
// 本地同步设置
dataSourceThreshold<int>._(110); // 数据源切换阈值（数据库资产数量）
```

### 2. 设置项定义

**文件**: `lib/core/settings/app_setting.dart`

```dart
/// 数据源切换阈值（数据库资产数量）
/// 当数据库资产数量大于此值时，使用数据库数据源
/// 默认值：100
dataSourceThreshold<int>(StoreKey.dataSourceThreshold, 100);
```

### 3. 使用位置

**文件**: `lib/features/local_sync/services/data_source_selector.dart`

```dart
class DataSourceSelector {
  final int threshold;

  DataSourceSelector({
    required AppDatabase database,
    int? threshold,
  }) : threshold = threshold ?? AppSetting.get(Setting.dataSourceThreshold);
}
```

## 如何调整阈值

### 方法1：通过代码调整（运行时）

在代码中动态设置阈值：

```dart
import 'package:prismbox/core/settings/app_setting.dart';

// 设置阈值为 200
await AppSetting.set(Setting.dataSourceThreshold, 200);

// 获取当前阈值
final currentThreshold = AppSetting.get(Setting.dataSourceThreshold);
print('当前阈值: $currentThreshold');
```

### 方法2：在设置页面中添加配置项（推荐）

在应用的设置页面中添加一个配置项，允许用户调整：

```dart
// 在设置页面中
ListTile(
  title: Text('数据源切换阈值'),
  subtitle: Text('当数据库资产数量大于此值时，使用数据库数据源（当前: ${AppSetting.get(Setting.dataSourceThreshold)}）'),
  trailing: TextField(
    onChanged: (value) async {
      final threshold = int.tryParse(value);
      if (threshold != null && threshold > 0) {
        await AppSetting.set(Setting.dataSourceThreshold, threshold);
      }
    },
  ),
)
```

### 方法3：修改默认值（编译时）

如果需要修改默认值，修改 `app_setting.dart`：

```dart
dataSourceThreshold<int>(StoreKey.dataSourceThreshold, 200); // 从 100 改为 200
```

## 阈值含义

- **数据库资产数量 > 阈值**：使用数据库数据源
  - 优势：查询性能好，支持复杂筛选，包含完整元数据
  - 适用：数据已同步完成的场景

- **数据库资产数量 ≤ 阈值**：使用 photo_manager 数据源
  - 优势：立即可用，无需等待同步
  - 适用：首次启动、数据库为空、手动刷新

## 阈值选择建议

| 场景 | 建议阈值 | 说明 |
|------|---------|------|
| 性能优先 | 50-80 | 更早切换到数据库，享受性能优势 |
| 平衡（默认） | 100 | 确保有足够数据，避免频繁切换 |
| 保守策略 | 150-200 | 确保数据库数据非常充足 |
| 大量媒体 | 100-150 | 适合有数千张照片的场景 |

## 验证配置是否生效

### 1. 查看初始化日志

应用启动时，应该看到：
```
[INFO] [DataSourceSelector] DataSourceSelector 初始化，阈值=100（从配置读取）
```

### 2. 查看数据源选择日志

选择数据源时，应该看到：
```
[FINE] [DataSourceSelector] 选择数据源：数据库（资产数量=150 > 阈值=100）
```
或
```
[FINE] [DataSourceSelector] 选择数据源：photo_manager（资产数量=50 ≤ 阈值=100）
```

### 3. 查看同步完成后的日志

同步完成后，应该看到：
```
[INFO] [SyncCoordinator] 检查数据源切换：数据库资产数量=150, 可用=true
[INFO] [SyncCoordinator] ✅ 数据库数据可用（资产数量=150），通知切换到数据库数据源
```

## 代码示例

### 示例1：在代码中动态调整阈值

```dart
import 'package:prismbox/core/settings/app_setting.dart';

// 获取当前阈值
final currentThreshold = AppSetting.get(Setting.dataSourceThreshold);
print('当前阈值: $currentThreshold');

// 设置为新值
await AppSetting.set(Setting.dataSourceThreshold, 150);

// 验证设置是否生效
final newThreshold = AppSetting.get(Setting.dataSourceThreshold);
print('新阈值: $newThreshold'); // 应该输出 150
```

### 示例2：监听阈值变化

```dart
import 'package:prismbox/core/settings/app_setting.dart';

// 监听阈值变化
AppSetting.watch(Setting.dataSourceThreshold).listen((threshold) {
  print('阈值已更新为: $threshold');
  // 可以在这里触发数据源重新选择
});
```

### 示例3：创建自定义阈值的 DataSourceSelector

```dart
// 创建使用自定义阈值的选择器
final selector = DataSourceSelector(
  database: database,
  threshold: 200, // 使用自定义阈值，而不是从配置读取
);
```

## 注意事项

1. **阈值必须是正整数**：建议范围 10-500
2. **阈值过小**：可能过早切换到数据库，但数据库数据不足
3. **阈值过大**：可能长时间使用 photo_manager，无法享受数据库性能优势
4. **配置持久化**：阈值存储在本地数据库中，应用重启后仍然有效
5. **实时生效**：修改阈值后，下次创建 `DataSourceSelector` 时会使用新值
