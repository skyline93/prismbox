## 模块概述

### 职责范围

页面导航模块是 PrismBox 移动端的用户界面导航层，负责：

1. **页面导航管理**：提供统一的导航容器（TabShell）和路由系统
2. **路由配置**：使用 AutoRoute 管理应用的路由结构和页面跳转
3. **导航守卫**：通过路由守卫控制页面访问权限和导航流程
4. **UI 组织**：管理四个核心标签页（照片、搜索、相册、资料库）的展示和切换
5. **查看器页面**：提供全屏媒体查看器，支持滑动切换和缩放
6. **响应式布局**：自动适配竖屏/横屏，切换导航栏位置

### 核心目标

1. **流畅导航**：提供流畅的页面切换动画和交互体验
2. **响应式设计**：自动适配不同屏幕尺寸和方向
3. **状态隔离**：每个标签页独立维护状态，切换时按需刷新
4. **类型安全**：使用 AutoRoute 的代码生成机制，提供编译时类型检查
5. **权限控制**：通过路由守卫精确控制页面访问权限

### 设计原则

1. **单导航容器架构**：TabShell 作为唯一的导航容器，管理所有主要页面
2. **状态隔离**：每个标签页独立维护状态，避免相互干扰
3. **渐进式加载**：按需加载页面内容和数据
4. **流畅动画**：使用 600ms 淡入淡出动画，提供平滑过渡体验
5. **权限先行**：所有主要页面都需要通过认证守卫

## 架构设计

### 整体架构

页面导航模块采用 **单导航容器架构（TabShell）**，通过 AutoRoute 管理路由，使用 Riverpod 进行状态管理。

```
│  ┌──────────────────────────────────────────────────────┐   │
│  │  SplashRoute → LoginRoute → PermissionRoute         │   │
│  └──────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
                            │
                            │ 认证完成
                            │
┌─────────────────────────────────────────────────────────────┐
│                  TabShell (导航容器)                          │
│                                                               │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐   │
```

### TabShell 容器架构

TabShell 是应用的主导航容器，使用 AutoRoute 的 `CustomRoute` 包装，包含四个子路由。

**架构特点**：
- 使用 `AutoTabsRouter` 管理标签页路由
- 支持响应式布局（竖屏/横屏）
- 每个标签页独立维护状态
- 600ms 淡入淡出过渡动画

### 路由架构

使用 AutoRoute 进行路由管理，提供类型安全的路由配置。

**路由层次结构**：
```
AppRouter (根路由)
├── SplashRoute (初始页面)
├── LoginRoute (登录页面)
├── PermissionRoute (权限引导)
├── TabShellRoute (主导航容器)
│   ├── MainTimelineRoute (照片时间线)
│   ├── SearchRoute (搜索)
│   ├── AlbumsRoute (相册)
│   └── LibraryRoute (资料库)
├── MediaViewerRoute (媒体查看器)
├── AlbumDetailRoute (相册详情)
├── SettingsRoute (设置)
└── ... (其他功能页面)
```

### 路由守卫架构

路由守卫系统控制页面访问权限和导航流程，包括：

1. **AuthGuard**：认证守卫，检查用户登录状态
2. **DuplicateGuard**：重复导航守卫，防止重复导航
3. **PermissionGuard**：权限守卫，检查特定权限

### 技术选型

1. **AutoRoute 8.x**：类型安全的路由管理和代码生成
2. **Riverpod 2.x**：状态管理和依赖注入
3. **Material 3**：响应式导航组件（NavigationBar / NavigationRail）

```dart
@AutoRouterConfig(replaceInRouteName: 'Page,Route')
class AppRouter extends _$AppRouter {
  final Ref ref;
  late final AuthGuard _authGuard;
  late final DuplicateGuard _duplicateGuard;
  late final PermissionGuard _permissionGuard;

  AppRouter(this.ref) {
    final apiService = ref.read(apiServiceProvider);
    _authGuard = AuthGuard(apiService);
    _duplicateGuard = const DuplicateGuard();
    _permissionGuard = PermissionGuard(ref);

  @override
  RouteType get defaultRouteType => const RouteType.material();

  @override
  List<AutoRoute> get routes => [

    AutoRoute(
      page: SplashRoute.page,
      path: '/splash',
      initial: true,
    ),
    
    // 登录页面（无守卫）
    AutoRoute(
      page: LoginRoute.page,
      path: '/login',
    ),
    
    // 权限引导页面（需要认证但不强制）
    AutoRoute(
      page: PermissionRoute.page,
      path: '/permission',
      guards: [_authGuard],
    ),
    
    // TabShell 容器（需要认证）
    CustomRoute(
      page: TabShellRoute.page,
      path: '/home',
      guards: [_authGuard, _duplicateGuard],
      children: [
        AutoRoute(
          page: MainTimelineRoute.page,
          path: '/photos',
          guards: [_authGuard],
        ),
        AutoRoute(
          page: SearchRoute.page,
          path: '/search',
          guards: [_authGuard],

          page: AlbumsRoute.page,

          guards: [_authGuard],
```

### 路由守卫组件

#### AuthGuard（认证守卫）

**文件位置**：`lib/presentation/routing/guards/auth_guard.dart`

**职责**：
- 检查用户是否已登录
- 验证访问令牌有效性
- 未登录时重定向到登录页面

**实现要点**：

```dart
class AuthGuard extends AutoRouteGuard {
  final ApiService _apiService;
  final _log = Logger('AuthGuard');

  AuthGuard(this._apiService);

  @override
  void onNavigation(
    NavigationResolver resolver,
    StackRouter router,
  ) async {
    // 先允许导航，后续验证失败则重定向
    resolver.next(true);

    try {
      // 检查存储中的访问令牌
      final accessToken = await _secureStorage.getAccessToken();
      if (accessToken == null || accessToken.isEmpty) {
        _log.warning('No access token found. Redirecting to login.');
        router.replaceAll([const LoginRoute()]);
        return;
      }

      // 同步 ApiService 中的 token
      final storedToken = _apiService.getAccessToken();
      if (storedToken != accessToken) {
        await _apiService.setAccessToken(accessToken);
      }

      // 验证服务器连接（替代 validateAccessToken 方法）
      // 通过 ping 服务器来验证 token 有效性
      try {
        await _apiService.pingServer();
      } on ApiException catch (e) {
        // 如果是 401 错误，说明 token 无效
        if (e.statusCode == 401) {
          _log.warning('Token validation failed (401). Redirecting to login.');
          await _apiService.clearAccessToken();
          router.replaceAll([const LoginRoute()]);
          return;
        }
        // 其他 API 错误（如 500 等）不影响导航，继续执行
        _log.fine('Server ping failed with API error, but continuing navigation: $e');
      } catch (e) {
        // 网络错误等其他异常不影响导航，继续执行
        _log.fine('Server ping failed, but continuing navigation: $e');
      }
    } catch (e) {
      _log.severe('Error validating access token: $e');
      // 验证失败时重定向到登录页
      unawaited(router.replaceAll([const LoginRoute()]));
    }
  }
}
```

#### DuplicateGuard（重复导航守卫）

**文件位置**：`lib/presentation/routing/guards/duplicate_guard.dart`

**职责**：
- 防止重复导航到同一页面
- 避免导航栈混乱

**实现要点**：

```dart
class DuplicateGuard extends AutoRouteGuard {
  const DuplicateGuard();

  @override
  void onNavigation(
    NavigationResolver resolver,
    StackRouter router,
  ) {
    final routeName = resolver.route.name;
    final currentRoute = router.current?.name;

    // 如果目标路由与当前路由相同，阻止导航
    if (routeName == currentRoute) {
      resolver.next(false);
      return;
    }

    resolver.next(true);
  }
}
```

### 路由导航流程

**流程图**：

```
用户操作
    │
    ├─ 点击导航栏标签
    │    │
    │    ├─ 检查是否已激活
    │    │    ├─ 是 → 执行标签特定行为（滚动到顶部/聚焦搜索）
    │    │    └─ 否 → 继续导航流程

    │    │

    │    │    └─ 更新导航栏状态
    │    │
    │    └─ 触发数据刷新
    │         ├─ 按需刷新 Provider
    │         └─ 更新页面状态

              └─ 恢复页面状态
```

**步骤说明**：

1. **用户触发导航**：点击导航栏标签或页面内链接

3. **导航执行**：通过 AutoRoute 执行页面切换
4. **状态更新**：更新导航状态和页面数据

#### AuthGuard 实现

```dart
class AuthGuard extends AutoRouteGuard {
  final ApiService _apiService;
  final SecureStorageService _secureStorage;
  final _log = Logger('AuthGuard');

  AuthGuard(this._apiService)
      : _secureStorage = SecureStorageService();

  @override
  void onNavigation(
    NavigationResolver resolver,
    StackRouter router,
  ) async {
    // 先允许导航，后续验证失败则重定向
    resolver.next(true);

    try {
      // 检查存储中的访问令牌
      final accessToken = await _secureStorage.getAccessToken();
      if (accessToken == null || accessToken.isEmpty) {
        _log.warning('No access token found. Redirecting to login.');
        router.replaceAll([const LoginRoute()]);
        return;
      }

      // 同步 ApiService 中的 token
      final storedToken = _apiService.getAccessToken();
      if (storedToken != accessToken) {
        await _apiService.setAccessToken(accessToken);
      }

      // 验证服务器连接（替代 validateAccessToken 方法）
      // 通过 ping 服务器来验证 token 有效性
      try {
        await _apiService.pingServer();
      } on ApiException catch (e) {
        // 如果是 401 错误，说明 token 无效
        if (e.statusCode == 401) {
          _log.warning('Token validation failed (401). Redirecting to login.');
          await _apiService.clearAccessToken();
          router.replaceAll([const LoginRoute()]);
          return;
        }
        // 其他 API 错误（如 500 等）不影响导航，继续执行
        _log.fine('Server ping failed with API error, but continuing navigation: $e');
      } catch (e) {
        // 网络错误等其他异常不影响导航，继续执行
        _log.fine('Server ping failed, but continuing navigation: $e');
      }
    } catch (e) {
      _log.severe('Error validating access token: $e');
      // 验证失败时重定向到登录页
      router.replaceAll([const LoginRoute()]);
    }
  }
}
```

### 常见问题

#### 问题 1：路由代码生成失败

**原因**：路由定义有语法错误或依赖问题

**解决方案**：
1. 检查路由定义语法
2. 确保所有页面都使用 `@RoutePage()` 注解
3. 运行 `flutter pub get` 更新依赖
4. 清理生成文件后重新生成：`flutter pub run build_runner clean`

#### 问题 2：标签切换时页面状态丢失

**原因**：`maintainState` 设置为 `false` 或页面未正确保持状态

**解决方案**：
1. 检查路由配置中的 `maintainState` 属性
2. 使用 `AutomaticKeepAliveClientMixin` 保持页面状态
3. 使用 Provider 管理页面状态

#### 问题 3：导航栏在横屏时不显示

**原因**：响应式布局判断逻辑错误

**解决方案**：
1. 检查 `MediaQuery.of(context).orientation` 判断逻辑
2. 确保横屏时使用 `NavigationRail` 而不是 `NavigationBar`
3. 检查 `isScreenLandscape` 变量的计算逻辑

#### 问题 4：路由守卫导致无限重定向

**原因**：守卫逻辑错误，导致循环重定向

**解决方案**：
1. 检查守卫中的重定向逻辑
2. 确保重定向目标路由不包含相同的守卫
3. 添加日志记录，追踪重定向路径

#### 问题 5：Hero 动画不流畅

**原因**：Hero tag 不唯一或动画配置不当

**解决方案**：
1. 确保每个 Hero widget 使用唯一的 tag
2. 使用 `HeroAttributes` 配置动画参数
3. 避免在动画过程中进行复杂计算

#### 问题 6：查看器页面内存泄漏

**原因**：未正确释放资源（控制器、监听器等）

**解决方案**：
1. 在 `dispose` 方法中释放所有资源
2. 取消所有定时器和监听器
3. 使用 `ref.onDispose` 管理 Provider 资源

3. **响应式设计**：自动适配竖屏/横屏，切换导航栏位置
4. **状态隔离**：每个标签页独立维护状态，切换时按需刷新
5. **流畅动画**：600ms 淡入淡出过渡动画，提供平滑用户体验
6. **权限控制**：通过路由守卫精确控制页面访问权限

### A. 路由配置示例

完整的路由配置示例：

```dart
@AutoRouterConfig(replaceInRouteName: 'Page,Route')
class AppRouter extends _$AppRouter {
  final Ref ref;
  late final AuthGuard _authGuard;
  late final DuplicateGuard _duplicateGuard;
  late final PermissionGuard _permissionGuard;

  AppRouter(this.ref) {
    final apiService = ref.read(apiServiceProvider);
    _authGuard = AuthGuard(apiService);
    _duplicateGuard = const DuplicateGuard();
    _permissionGuard = PermissionGuard(ref);
  }

  @override
  RouteType get defaultRouteType => const RouteType.material();

  @override
  List<AutoRoute> get routes => [
    // 初始页面（无守卫）
    AutoRoute(
      page: SplashRoute.page,
      path: '/splash',
      initial: true,
    ),
    
    // 登录页面（无守卫）
    AutoRoute(
      page: LoginRoute.page,
      path: '/login',
    ),
    
    // 权限引导页面（需要认证但不强制）
    AutoRoute(
      page: PermissionRoute.page,
      path: '/permission',
      guards: [_authGuard],
    ),
    
    // TabShell 容器（需要认证）
    CustomRoute(
      page: TabShellRoute.page,
      path: '/home',
      guards: [_authGuard, _duplicateGuard],
      children: [
        AutoRoute(
          page: MainTimelineRoute.page,
          path: '/photos',
          guards: [_authGuard],
        ),
        AutoRoute(
          page: SearchRoute.page,
          path: '/search',
          guards: [_authGuard],
          maintainState: false, // 不保持状态
        ),
        AutoRoute(
          page: AlbumsRoute.page,
          path: '/albums',
          guards: [_authGuard],
        ),
        AutoRoute(
          page: LibraryRoute.page,
          path: '/library',
          guards: [_authGuard],
        ),
      ],
      transitionsBuilder: TransitionsBuilders.fadeIn,
    ),
    
    // 媒体查看器（需要认证和权限）
    AutoRoute(
      page: MediaViewerRoute.page,
      path: '/media/:assetId',
      guards: [_authGuard, _permissionGuard],
    ),
  ];
}
```

```dart
// AuthGuard
class AuthGuard extends AutoRouteGuard {
  final ApiService _apiService;
  final SecureStorageService _secureStorage;
  final _log = Logger('AuthGuard');

  AuthGuard(this._apiService)
      : _secureStorage = SecureStorageService();

  @override
  void onNavigation(
    NavigationResolver resolver,
    StackRouter router,
  ) async {
    resolver.next(true);

    try {
      final accessToken = await _secureStorage.getAccessToken();
      if (accessToken == null || accessToken.isEmpty) {
        _log.warning('No access token. Redirecting to login.');
        router.replaceAll([const LoginRoute()]);
        return;
      }

      // 同步 ApiService 中的 token
      final storedToken = _apiService.getAccessToken();
      if (storedToken != accessToken) {
        await _apiService.setAccessToken(accessToken);
      }

      // 验证服务器连接（替代 validateAccessToken 方法）
      try {
        await _apiService.pingServer();
      } on ApiException catch (e) {
        if (e.statusCode == 401) {
          _log.warning('Token validation failed (401). Redirecting to login.');
          await _apiService.clearAccessToken();
          router.replaceAll([const LoginRoute()]);
          return;
        }
        _log.fine('Server ping failed with API error, but continuing navigation: $e');
      } catch (e) {
        _log.fine('Server ping failed, but continuing navigation: $e');
      }
    } catch (e) {
      _log.severe('AuthGuard error: $e');
      router.replaceAll([const LoginRoute()]);
    }
  }
}

// DuplicateGuard
class DuplicateGuard extends AutoRouteGuard {
  const DuplicateGuard();

  @override
  void onNavigation(
    NavigationResolver resolver,
    StackRouter router,
  ) {
    final targetRoute = resolver.route;
    final currentRoute = router.current;

    if (currentRoute != null && // ignore: unnecessary_null_comparison
        targetRoute.name == currentRoute.name &&
        targetRoute.path == currentRoute.path) {
      resolver.next(false);
      return;
    }

    resolver.next(true);
  }
}
```
