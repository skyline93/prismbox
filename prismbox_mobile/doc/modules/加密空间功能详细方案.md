## 加密空间功能详细方案（基于相册组织）

### 一、核心设计理念

1.  **加密空间是特殊相册**：
    *   远程加密相册：`RemoteAlbumEntity` 中 `isEncrypted=true` 的相册
    *   本地加密相册：`LocalAlbumEntity` 中 `isEncrypted=true` 的相册
2.  **通过相册组织资产**：
    *   远程资产：使用 `AlbumAssetEntity` 关联到远程加密相册
    *   本地资产：使用 `LocalAlbumAssetEntity` 关联到本地加密相册
3.  **访问控制**：相册级别验证，未验证不可查看相册内容
4.  **安全存储**：仅本地资产添加到加密空间时，文件迁移到应用私有目录
5.  **后端密码验证**：后端存储密码哈希，API调用需要密码验证，确保脱离移动端也安全
6.  **可扩展性**：后续普通相册可设置 `isEncrypted=true`

### 三、加密空间管理逻辑

#### 3.1 加密空间相册创建

**远程加密空间相册**

*   相册ID：`__encrypted_space__`（固定ID）
*   相册属性：`isEncrypted = true`, `name = "加密空间"`
*   创建时机：用户首次使用加密功能时自动创建

**本地加密空间相册**

*   相册ID：`__local_encrypted_space__`（固定ID）
*   相册属性：`isEncrypted = true`, `name = "加密空间（本地）"`
*   创建时机：用户首次添加仅本地资产到加密空间时自动创建

#### 3.2 资产添加到加密空间

**处理逻辑**：

```plaintext
// 添加资产到加密空间的流程
Future<void> addAssetsToEncryptedSpace(List<baseasset> assets) async {
  // 1. 获取或创建加密空间相册（远程和本地）
  final remoteEncryptedAlbum = await getOrCreateRemoteEncryptedAlbum();
  final localEncryptedAlbum = await getOrCreateLocalEncryptedAlbum();

  for (final asset in assets) {
    // 2. 处理远程资产（有remoteId）
    if (asset.hasRemote) {
      // 通过 AlbumAssetEntity 关联到远程加密相册
      await albumDao.addAssetToAlbum(
        asset.remoteId!,
        remoteEncryptedAlbum.id,
      );

      // 同步到服务端
      await apiService.addAssetToAlbum(
        asset.remoteId!,
        remoteEncryptedAlbum.id,
      );
    }

    // 3. 处理本地资产（有localId）
    if (asset.hasLocal) {
      final localAsset = asset as LocalAsset;

      // 3.1 如果资产在系统相册，需要迁移到私有空间
      if (!localAsset.isInPrivateSpace) {
        await moveAssetToPrivateSpace(localAsset);
      }

      // 3.2 关联到本地加密相册
      await localAlbumDao.addAssetToAlbum(
        localAsset.id,
        localEncryptedAlbum.id,
      );
    }
  }
}
```

**三种资产状态的处理**：

**仅本地资产**（LocalAsset，remoteId == null）

*   迁移文件到应用私有目录
*   更新 `LocalAssetEntity.path` 指向新位置
*   设置 `LocalAssetEntity.isInPrivateSpace = true`
*   通过 `LocalAlbumAssetEntity` 关联到本地加密相册

**仅云端资产**（RemoteAsset，localId == null）

*   通过 `AlbumAssetEntity` 关联到远程加密相册
*   同步到服务端

**已备份资产**（LocalAsset + RemoteAsset，有 localId 和 remoteId）

*   远程资产：通过 `AlbumAssetEntity` 关联到远程加密相册
*   本地资产：如果未在私有空间，迁移到私有空间，然后关联到本地加密相册
*   同步到服务端

#### 3.3 资产迁移到私有空间

**实现逻辑**：

```plaintext
/// 将资产从系统相册迁移到应用私有目录
Future<void> moveAssetToPrivateSpace(LocalAsset asset) async {
  // 1. 获取应用私有目录
  final appDir = await getApplicationDocumentsDirectory();
  final privateSpaceDir = Directory('${appDir.path}/encrypted_space');
  if (!await privateSpaceDir.exists()) {
    await privateSpaceDir.create(recursive: true);
  }

  // 2. 读取原始文件
  final originalFile = File(asset.path);
  if (!await originalFile.exists()) {
    throw Exception('原始文件不存在: ${asset.path}');
  }

  // 3. 生成新文件路径（使用资产ID作为文件名，保留扩展名）
  final extension = path.extension(asset.path);
  final newFilePath = '${privateSpaceDir.path}/${asset.id}$extension';
  final newFile = File(newFilePath);

  // 4. 复制文件到私有目录
  await originalFile.copy(newFilePath);

  // 5. 更新数据库
  await localAssetDao.updatePath(asset.id, newFilePath);
  await localAssetDao.updateIsInPrivateSpace(asset.id, true);

  // 6. 可选：删除原始文件（如果用户确认）
  // await originalFile.delete();
}
```

**安全考虑**：

*   私有目录使用 `.nosync` 扩展名（iOS）防止 iCloud 同步
*   Android 使用内部存储目录，不在外部存储暴露
*   文件权限设置为仅应用可访问

### 四、访问控制机制

#### 4.1 相册级别的访问控制

**设计**：

*   相册级别验证，而非资产级别
*   验证后解锁该相册的访问权限
*   使用内存状态管理解锁状态
*   **后端API也需要密码验证**

**解锁状态管理**：

```plaintext
class AlbumAccessControl {
  // 已解锁的相册ID集合（内存中）
  final Set<string> _unlockedAlbumIds = {};

  // 解锁时间记录（用于自动锁定）
  final Map<string, datetime=""> _unlockTimes = {};

  // 解锁相册（需要验证密码）
  Future<bool> unlockAlbum(String albumId, {
    String? password,
    bool useBiometric = false,
  }) async {
    // 1. 生物识别验证（如果可用）
    if (useBiometric) {
      final success = await authService.authenticateWithBiometrics();
      if (success) {
        // 从 secure storage 获取密码，用于后端验证
        password = await secureStorage.read(key: 'encryption_space_password');
      }
    }

    // 2. 后端验证密码（确保API安全）
    if (password != null) {
      final isValid = await apiService.verifyAlbumPassword(albumId, password);
      if (!isValid) {
        return false;
      }
    }

    // 3. 本地也验证（双重验证）
    final localValid = await authService.verifyPassword(password, albumId);
    if (!localValid) {
      return false;
    }

    // 4. 解锁成功
    _unlockedAlbumIds.add(albumId);
    _unlockTimes[albumId] = DateTime.now();
    return true;
  }

  // 检查相册是否已解锁
  bool isAlbumUnlocked(String albumId) {
    return _unlockedAlbumIds.contains(albumId);
  }

  // 锁定相册
  void lockAlbum(String albumId) {
    _unlockedAlbumIds.remove(albumId);
    _unlockTimes.remove(albumId);
  }
}
```

#### 4.2 密码/密钥管理

**设计**：

*   **后端存储密码哈希**：在 `albums` 表的 `password_hash` 字段
*   **移动端也存储密码哈希**：在 `flutter_secure_storage` 中作为备份
*   使用 bcrypt 或 Argon2 存储密码哈希
*   统一密码策略：所有加密相册使用同一密码

**密码设置流程**：

```plaintext
// 设置加密空间密码
Future<void> setEncryptionPassword(String password) async {
  // 1. 生成密码哈希
  final passwordHash = await authService.hashPassword(password);

  // 2. 存储到后端（远程加密相册）
  final remoteAlbum = await getOrCreateRemoteEncryptedAlbum();
  await apiService.setAlbumPassword(remoteAlbum.id, passwordHash);

  // 3. 存储到本地 secure storage（作为备份）
  await secureStorage.write(
    key: 'encryption_space_password_hash',
    value: passwordHash,
  );

  // 4. 存储明文密码到 secure storage（用于生物识别）
  // 注意：这是为了生物识别后自动获取密码用于API验证
  await secureStorage.write(
    key: 'encryption_space_password',
    value: password,
  );
}
```

#### 4.3 自动锁定机制

**机制**：

*   解锁后启动定时器（如30分钟）
*   时间到自动锁定
*   应用进入后台时锁定所有加密相册

#### 6.2 API密码验证中间件

**后端实现**：

```plaintext
// 加密相册密码验证中间件
func VerifyAlbumPassword() gin.HandlerFunc {
  return func(c *gin.Context) {
    albumId := c.Param("albumId")

    // 1. 检查相册是否存在且为加密相册
    album, err := albumService.GetAlbum(albumId)
    if err != nil || !album.IsEncrypted {
      c.JSON(404, gin.H{"error": "Album not found or not encrypted"})
      c.Abort()
      return
    }

    // 2. 获取密码（从Header或Body）
    password := c.GetHeader("X-Album-Password")
    if password == "" {
      var req struct {
        Password string `json:"password"`
      }
      if err := c.ShouldBindJSON(&amp;req); err != nil {
        password = req.Password
      }
    }

    if password == "" {
      c.JSON(401, gin.H{"error": "Password required"})
      c.Abort()
      return
    }

    // 3. 验证密码
    if !bcrypt.CompareHashAndPassword([]byte(album.PasswordHash), []byte(password)) {
      c.JSON(403, gin.H{"error": "Invalid password"})
      c.Abort()
      return
    }

    // 4. 验证通过，继续处理
    c.Next()
  }
}
```

### 八、安全考虑

#### 8.1 访问控制安全

1.  **双重验证**：本地验证 + 后端API验证
2.  **密码存储**：后端存储密码哈希，移动端也存储作为备份
3.  **解锁状态**：仅存在内存，应用重启需重新验证
4.  **自动锁定**：防止长时间未锁定
5.  **API安全**：所有加密相册相关API都需要密码验证

#### 8.2 数据安全

1.  **文件安全**：仅本地资产迁移到应用私有目录，不在系统相册暴露
2.  **私有目录**：使用 `.nosync` 防止 iCloud 同步（iOS）
3.  **访问控制**：未解锁时，加密相册的资产不在列表中显示
4.  **后端验证**：即使脱离移动端，调用API也需要密码验证

#### 8.3 传输安全

1.  **HTTPS**：所有 API 调用使用 HTTPS
2.  **密码传输**：密码通过 Header 或加密请求体传输
3.  **Token认证**：使用现有的 JWT Token 认证用户身份
4.  **密码验证**：额外的相册密码验证层

#### 10.1 文件迁移到私有空间

```plaintext
Future<void> moveAssetToPrivateSpace(LocalAsset asset) async {
  // 1. 获取应用私有目录
  final appDir = await getApplicationDocumentsDirectory();
  final privateSpaceDir = Directory('${appDir.path}/encrypted_space');

  // 2. 确保目录存在
  if (!await privateSpaceDir.exists()) {
    await privateSpaceDir.create(recursive: true);
  }

  // 3. 读取原始文件
  final originalFile = File(asset.path);
  final fileData = await originalFile.readAsBytes();

  // 4. 生成新文件路径
  final extension = path.extension(asset.path);
  final newFilePath = '${privateSpaceDir.path}/${asset.id}$extension';

  // 5. 写入私有目录
  final newFile = File(newFilePath);
  await newFile.writeAsBytes(fileData);

  // 6. 更新数据库
  await localAssetDao.updatePath(asset.id, newFilePath);
  await localAssetDao.updateIsInPrivateSpace(asset.id, true);
}
```

#### 10.2 后端密码验证

```plaintext
// 验证相册密码的中间件
func VerifyAlbumPasswordMiddleware() gin.HandlerFunc {
  return func(c *gin.Context) {
    albumId := c.Param("albumId")

    // 获取相册信息
    album := getAlbum(albumId)
    if !album.IsEncrypted {
      c.Next() // 非加密相册，跳过验证
      return
    }

    // 获取密码
    password := c.GetHeader("X-Album-Password")

    // 验证密码
    if !bcrypt.CompareHashAndPassword([]byte(album.PasswordHash), []byte(password)) {
      c.JSON(403, gin.H{"error": "Invalid password"})
      c.Abort()
      return
    }

    c.Next()
  }
}
```

### 十一、总结

**方案要点**：

1.  **基于相册组织**：加密空间是 `isEncrypted=true` 的特殊相册（远程和本地）
2.  **完整支持**：支持仅本地资产、仅云端资产、已备份资产
3.  **安全存储**：仅本地资产迁移到应用私有目录
4.  **后端验证**：后端存储密码哈希，API调用需要密码验证
5.  **双重验证**：本地验证 + 后端API验证，确保安全
6.  **简洁设计**：最小化表扩展，复用现有结构

**优势**：

*   表设计简洁，只需扩展几个字段和新增一个关联表
*   完整支持所有资产类型
*   后端API安全，即使脱离移动端也安全
*   文件安全，仅本地资产不在系统相册暴露
*   可扩展性好，后续可支持多加密相册

**关键特性**：

*   ✅ 仅本地资产支持加密空间
*   ✅ 资产迁移到私有空间
*   ✅ 后端密码存储和验证
*   ✅ API级别安全验证
