## 模块概述

### 职责范围

数据库模块是 PrismBox 移动端的数据持久化层，负责：

1. **数据持久化**：使用 Drift (SQLite) 存储所有关系型数据
2. **数据访问抽象**：提供类型安全的数据访问接口（DAO）
3. **数据一致性保证**：通过外键约束和事务保证数据完整性
4. **数据迁移管理**：支持版本化的数据库结构升级
5. **跨 Isolate 支持**：支持在多个 Dart Isolate 中共享数据库连接

### 核心目标

1. **类型安全**：使用 Drift 的代码生成机制，提供编译时类型检查
2. **高性能**：通过合理的索引设计、查询优化和 WAL 模式提升性能
3. **可扩展性**：支持渐进式的数据库结构升级，保持向后兼容
4. **数据完整性**：通过外键约束和删除策略保证数据一致性
5. **开发效率**：提供简洁的 API，减少样板代码

### 设计原则

1. **本地与远程数据分离**：本地资产和远程资产分别存储，通过 `checksum` 关联
2. **严格模式**：所有表使用 `WITHOUT ROWID` 和 `STRICT` 模式，提升性能和类型安全
3. **业务主键**：所有表使用业务主键（String 类型），不使用自增 ID
4. **外键约束**：完整的外键约束保证数据一致性
5. **版本化迁移**：支持渐进式数据库结构升级

### 核心组件

1. **AppDatabase**：数据库主文件，管理数据库连接和配置
2. **Connection**：数据库连接管理，支持跨 Isolate 共享
3. **Tables**：表定义，使用 Drift 的 Table 类定义
4. **DAOs**：数据访问对象，提供类型安全的查询接口
5. **Migrations**：迁移脚本，管理数据库结构升级

### 技术选型

**选择 Drift 的理由**：

1. **类型安全**：编译时类型检查，减少运行时错误
2. **代码生成**：自动生成 DAO 和查询代码，减少样板代码
3. **迁移支持**：完善的迁移机制，支持版本化升级
4. **跨平台**：支持所有 Flutter 平台（iOS、Android、Web、Desktop）
5. **性能优秀**：基于 SQLite，性能优秀，支持复杂查询
6. **成熟稳定**：基于成熟的 SQLite 和 Moor（Drift 前身）项目

**权衡**：
- 需要编写 SQL 查询（但 Drift 提供了类型安全的 API）
- 相比 NoSQL 数据库，灵活性稍低（但关系型数据更适合我们的场景）

## 核心组件详解

### 1. AppDatabase - 数据库主文件

**职责**：
- 管理数据库连接和配置
- 定义所有表和 DAO
- 管理数据库迁移
- 提供事务支持

**实现要点**：

```dart
@DriftDatabase(tables: [
  LocalAssetEntity,
  RemoteAssetEntity,
  LocalAlbumEntity,
  RemoteAlbumEntity,
  AlbumAssetEntity,
  // ... 其他表
], daos: [
  LocalAssetDao,
  RemoteAssetDao,
  AlbumDao,
  // ... 其他 DAO
])
class AppDatabase extends _$AppDatabase {
  AppDatabase() : super(_openConnection());

  @override
  int get schemaVersion => 1;

  @override
  MigrationStrategy get migration {
    return MigrationStrategy(
      onCreate: (Migrator m) async {
        await m.createAll();
      },
      onUpgrade: (Migrator m, int from, int to) async {
        // 版本化迁移逻辑
      },
    );
  }
}
```

**关键配置**：

1. **跨 Isolate 支持**：
```dart
LazyDatabase _openConnection() {
  return LazyDatabase(() async {
    final dbFolder = await getApplicationDocumentsDirectory();
    final file = File(p.join(dbFolder.path, 'prismbox.db'));
    
    return NativeDatabase.createInBackground(
      file,
      setup: (database) {
        // SQLite PRAGMA 设置
        database.execute('PRAGMA foreign_keys = ON');
        database.execute('PRAGMA journal_mode = WAL');
        database.execute('PRAGMA synchronous = NORMAL');
        database.execute('PRAGMA busy_timeout = 30000');
      },
      shareAcrossIsolates: true, // 关键：支持跨 Isolate
    );
  });
}
```

2. **SQLite PRAGMA 设置**：
   - `foreign_keys = ON`：启用外键约束
   - `journal_mode = WAL`：使用 WAL 模式提升并发性能
   - `synchronous = NORMAL`：平衡性能和数据安全
   - `busy_timeout = 30000`：30 秒超时，避免并发冲突

### 2. Connection - 数据库连接管理

**职责**：
- 管理数据库连接的创建和关闭
- 支持跨 Isolate 共享连接
- 处理连接池和并发访问

**实现要点**：

```dart
class DatabaseConnection {
  static AppDatabase? _database;
  
  static Future<AppDatabase> getInstance() async {
    if (_database == null) {
      _database = AppDatabase();
    }
    return _database!;
  }
  
  static Future<void> close() async {
    await _database?.close();
    _database = null;
  }
}
```

**跨 Isolate 支持**：
- 使用 `NativeDatabase.createInBackground` 创建连接
- 设置 `shareAcrossIsolates: true` 允许在多个 Isolate 中共享
- 后台任务 Engine 可以访问同一个数据库实例

### 3. 表定义 (Tables)

#### 3.1 LocalAssetEntity - 本地资产表

**职责**：存储设备上的原始媒体文件信息

**表结构**：

```dart
@DataClassName('LocalAssetEntityData')
class LocalAssetEntity extends Table 
    with DriftDefaultsMixin, AssetEntityMixin {
  const LocalAssetEntity();

  // 主键
  TextColumn get id => text()();
  
  // 文件哈希（用于与远程资产关联）
  TextColumn get checksum => text().nullable()();
  
  // 是否收藏（用于备份时同步服务器状态）
  BoolColumn get isFavorite => boolean()
      .withDefault(const Constant(false))();
  
  // 图片方向（0-8，EXIF 方向值）
  IntColumn get orientation => integer()
      .withDefault(const Constant(0))();

  @override
  Set<Column> get primaryKey => {id};
}
```

**继承的 Mixin**：

1. **AssetEntityMixin**：通用资产字段
```dart
mixin AssetEntityMixin on Table {
  TextColumn get name => text()();
  IntColumn get type => intEnum<AssetType>()();
  DateTimeColumn get createdAt => dateTime()();
  DateTimeColumn get updatedAt => dateTime()();
  IntColumn get width => integer().nullable()();
  IntColumn get height => integer().nullable()();
  IntColumn get durationInSeconds => integer().nullable()();
}
```

2. **DriftDefaultsMixin**：默认值处理
```dart
mixin DriftDefaultsMixin on Table {
  // 提供默认的时间戳等
}
```

**索引**：
```dart
@TableIndex.sql(
  'CREATE INDEX IF NOT EXISTS idx_local_asset_checksum '
  'ON local_asset_entity (checksum)'
)
```

**设计要点**：
- `checksum` 可为空，因为文件可能尚未计算哈希
- `isFavorite` 用于在备份过程中同步服务器端的收藏状态
- `orientation` 存储 EXIF 方向信息，用于正确显示图片
- 使用 `WITHOUT ROWID` 和 `STRICT` 模式

#### 3.2 RemoteAssetEntity - 远程资产表

**职责**：存储从服务器同步的资产信息

**表结构**：

```dart
@DataClassName('RemoteAssetEntityData')
class RemoteAssetEntity extends Table 
    with DriftDefaultsMixin, AssetEntityMixin {
  const RemoteAssetEntity();

  // 主键（服务器端资产 ID）
  TextColumn get id => text()();
  
  // 文件哈希（必填，用于去重和关联）
  TextColumn get checksum => text()();
  
  // 是否收藏
  BoolColumn get isFavorite => boolean()
      .withDefault(const Constant(false))();
  
  // 所有者用户 ID
  TextColumn get ownerId => text()
      .references(UserEntity, #id, onDelete: KeyAction.cascade)();
  
  // 本地拍摄时间
  DateTimeColumn get localDateTime => dateTime().nullable()();
  
  // 缩略图哈希
  TextColumn get thumbHash => text().nullable()();
  
  // 删除时间（软删除）
  DateTimeColumn get deletedAt => dateTime().nullable()();
  
  // Live Photo 视频 ID
  TextColumn get livePhotoVideoId => text().nullable()();
  
  // 可见性枚举
  IntColumn get visibility => intEnum<AssetVisibility>()();
  
  // 堆叠 ID
  TextColumn get stackId => text().nullable()();
  
  // 库 ID（支持多库）
  TextColumn get libraryId => text().nullable()();

  @override
  Set<Column> get primaryKey => {id};
}
```

**索引**：
```dart
// 复合索引：按用户和哈希查找
@TableIndex.sql(
  'CREATE INDEX IF NOT EXISTS idx_remote_asset_owner_checksum '
  'ON remote_asset_entity (owner_id, checksum)'
)

// 条件唯一索引：单库场景
@TableIndex.sql('''
CREATE UNIQUE INDEX IF NOT EXISTS UQ_remote_assets_owner_checksum
ON remote_asset_entity (owner_id, checksum)
WHERE (library_id IS NULL);
''')

// 条件唯一索引：多库场景
@TableIndex.sql('''
CREATE UNIQUE INDEX IF NOT EXISTS UQ_remote_assets_owner_library_checksum
ON remote_asset_entity (owner_id, library_id, checksum)
WHERE (library_id IS NOT NULL);
''')

// 哈希索引：用于关联本地资产
@TableIndex.sql(
  'CREATE INDEX IF NOT EXISTS idx_remote_asset_checksum '
  'ON remote_asset_entity (checksum)'
)
```

**设计要点**：
- 使用条件唯一索引支持单库和多库场景
- `checksum` 与 `ownerId` 组合保证唯一性
- 软删除通过 `deletedAt` 实现
- 支持 Live Photo（iOS）和堆叠功能

### 4. DAO (Data Access Object)

#### 4.1 LocalAssetDao - 本地资产数据访问对象

**职责**：提供本地资产的查询和操作接口

**接口定义**：

```dart
@DriftAccessor(tables: [LocalAssetEntity])
class LocalAssetDao extends DatabaseAccessor<AppDatabase>
    with _$LocalAssetDaoMixin {
  LocalAssetDao(AppDatabase db) : super(db);

  // 获取所有本地资产
  Future<List<LocalAssetEntityData>> getAllAssets() {
    return select(localAssetEntity).get();
  }

  // 根据 ID 获取资产
  Future<LocalAssetEntityData?> getAssetById(String id) {
    return (select(localAssetEntity)
          ..where((t) => t.id.equals(id)))
        .getSingleOrNull();
  }

  // 根据 checksum 获取资产
  Future<LocalAssetEntityData?> getAssetByChecksum(String checksum) {
    return (select(localAssetEntity)
          ..where((t) => t.checksum.equals(checksum)))
        .getSingleOrNull();
  }

  // 插入资产
  Future<void> insertAsset(LocalAssetEntityData asset) {
    return into(localAssetEntity).insert(asset);
  }

  // 批量插入资产
  Future<void> insertAssets(List<LocalAssetEntityData> assets) {
    return batch((batch) {
      batch.insertAll(localAssetEntity, assets);
    });
  }

  // 更新资产
  Future<bool> updateAsset(LocalAssetEntityData asset) {
    return update(localAssetEntity).replace(asset);
  }

  // 删除资产
  Future<bool> deleteAsset(String id) {
    return (delete(localAssetEntity)
          ..where((t) => t.id.equals(id)))
        .go();
  }

  // 流式查询：监听资产变化
  Stream<List<LocalAssetEntityData>> watchAssets() {
    return select(localAssetEntity).watch();
  }

  // 按类型筛选资产
  Future<List<LocalAssetEntityData>> getAssetsByType(AssetType type) {
    return (select(localAssetEntity)
          ..where((t) => t.type.equals(type.index)))
        .get();
  }

  // 按时间范围查询资产
  Future<List<LocalAssetEntityData>> getAssetsByDateRange(
    DateTime start,
    DateTime end,
  ) {
    return (select(localAssetEntity)
          ..where((t) => t.createdAt.isBetweenValues(start, end))
          ..orderBy([(t) => OrderingTerm.desc(t.createdAt)]))
        .get();
  }
}
```

#### 4.2 RemoteAssetDao - 远程资产数据访问对象

**职责**：提供远程资产的查询和操作接口

**接口定义**：

```dart
@DriftAccessor(tables: [RemoteAssetEntity])
class RemoteAssetDao extends DatabaseAccessor<AppDatabase>
    with _$RemoteAssetDaoMixin {
  RemoteAssetDao(AppDatabase db) : super(db);

  // 获取用户的所有资产（排除已删除）
  Future<List<RemoteAssetEntityData>> getUserAssets(String userId) {
    return (select(remoteAssetEntity)
          ..where((t) => 
              t.ownerId.equals(userId) & 
              t.deletedAt.isNull()))
        .get();
  }

  // 根据 checksum 和用户 ID 获取资产
  Future<RemoteAssetEntityData?> getAssetByChecksumAndUser(
    String checksum,
    String userId,
  ) {
    return (select(remoteAssetEntity)
          ..where((t) => 
              t.checksum.equals(checksum) & 
              t.ownerId.equals(userId) &
              t.deletedAt.isNull()))
        .getSingleOrNull();
  }

  // 软删除资产
  Future<bool> softDeleteAsset(String id) {
    return (update(remoteAssetEntity)
          ..where((t) => t.id.equals(id)))
        .write(RemoteAssetEntityCompanion(
          deletedAt: Value(DateTime.now()),
        ));
  }

  // 恢复软删除的资产
  Future<bool> restoreAsset(String id) {
    return (update(remoteAssetEntity)
          ..where((t) => t.id.equals(id)))
        .write(RemoteAssetEntityCompanion(
          deletedAt: const Value.absent(),
        ));
  }

  // 流式查询：监听用户资产变化
  Stream<List<RemoteAssetEntityData>> watchUserAssets(String userId) {
    return (select(remoteAssetEntity)
          ..where((t) => 
              t.ownerId.equals(userId) & 
              t.deletedAt.isNull()))
        .watch();
  }

  // 批量更新资产
  Future<void> updateAssets(List<RemoteAssetEntityData> assets) {
    return batch((batch) {
      for (final asset in assets) {
```

```dart
  switch (version) {
```

### 常见问题和解决方案

#### 1. 代码生成失败

**问题**：`build_runner` 生成代码时出错

**解决方案**：
- 检查表定义语法是否正确
- 删除 `*.g.dart` 和 `*.drift.dart` 文件后重新生成
- 使用 `--delete-conflicting-outputs` 参数

#### 2. 跨 Isolate 访问失败

**问题**：在后台 Isolate 中无法访问数据库

**解决方案**：
- 确保使用 `NativeDatabase.createInBackground` 创建连接
- 设置 `shareAcrossIsolates: true`
- 确保所有 Isolate 使用相同的数据库文件路径

#### 3. 迁移失败

**问题**：数据库迁移时出错

**解决方案**：
- 检查迁移脚本语法
- 使用事务包装迁移步骤
- 在测试环境中验证迁移脚本
- 提供回滚机制

#### 4. 性能问题

**问题**：查询或写入性能不佳

**解决方案**：
- 检查是否使用了索引
- 使用批量操作代替循环插入
- 使用 WAL 模式
- 优化查询语句（避免全表扫描）

#### 5. 外键约束错误

**问题**：插入数据时违反外键约束

**解决方案**：
- 检查外键引用的记录是否存在
- 确保删除策略正确（CASCADE/SET NULL）
- 在调试模式下检查外键完整性
