## 模块概述

### 职责范围

媒体资源展示模块是 PrismBox 移动端的核心展示模块，负责：

1. **多级渐进式加载**：实现占位符 → 缩略图 → 预览图 → 原图的渐进式加载策略
2. **智能资源选择**：根据本地/远程资源可用性和用户偏好自动选择最优资源提供者
3. **多级缓存管理**：管理内存缓存和磁盘缓存，大图小图分离，优化缓存命中率
4. **占位符优化**：使用 ThumbHash 和渐变占位符提供即时视觉反馈
5. **可取消加载**：支持加载任务取消，避免资源浪费和内存泄漏
6. **流式加载**：支持边下载边解码，提升感知速度

### 核心目标

1. **流畅的用户体验**：快速显示内容，减少用户等待时间
2. **快速加载**：优化加载路径，优先使用缓存和本地资源
3. **内存优化**：严格控制内存使用，避免 OOM（Out of Memory）
4. **网络优化**：减少不必要的网络请求，节省带宽
5. **视觉体验**：渐进式加载提供平滑的视觉过渡

### 设计原则

1. **渐进式加载**：占位符 → 缩略图 → 预览图 → 原图，确保快速首屏
2. **智能资源选择**：本地优先，远程回退，尊重用户偏好
3. **多级缓存分离**：大图小图分离缓存，防止相互驱逐
4. **可取消加载**：组件销毁时自动取消，避免资源浪费
5. **平台原生集成**：充分利用平台原生 API 获取本地资源

### 与其他模块的关系

```
媒体资源展示模块
    │
    ├─→ API 对接模块：使用 ApiService 获取远程资源
    ├─→ 数据库模块：查询本地和远程资产信息
    ├─→ 备份上传下载模块：共享缓存机制和资源加载逻辑
    └─→ 页面导航模块：为 UI 组件提供图片加载能力
```

## 核心组件详解

### 1. ImageProvider 层

#### 1.1 本地资源提供者

**LocalThumbProvider**
- **用途**：加载本地资源的缩略图
- **实现方式**：使用 `photo_manager` 的 `thumbnailDataWithSize` API
- **缓存策略**：先检查磁盘缓存，未命中则生成并缓存
- **缓存键格式**：`{userId}{localId}{checksum}{width}{height}`

**LocalFullImageProvider**
- **用途**：加载本地资源的原图
- **实现方式**：
  - 图片：直接读取原文件
  - 视频：生成指定尺寸的缩略图
- **加载流程**：
  1. 先显示缩略图（从缓存或生成）
  2. 加载适配设备分辨率的图片
  3. 根据设置决定是否加载原图

#### 1.2 远程资源提供者

**RemoteThumbProvider**
- **用途**：加载远程资源的缩略图
- **URL 格式**：`/assets/{id}/thumbnail?size={size}`
- **缓存策略**：使用 `ThumbnailImageCacheManager`（5000 个对象，30 天过期）

**RemoteFullImageProvider**
- **用途**：加载远程资源的原图
- **加载流程**：
  1. 先加载预览图（Preview）
  2. 根据用户设置决定是否加载原图
- **URL 格式**：
  - 预览图：`/assets/{id}/thumbnail?size=preview`
  - 原图：`/assets/{id}/original`

#### 1.3 资源选择逻辑

**getThumbnailImageProvider / getFullImageProvider**
- **输入**：`BaseAsset`（本地或远程资源）
- **输出**：对应的 `ImageProvider`
- **选择逻辑**：
  ```dart
  bool _shouldUseLocalAsset(BaseAsset asset) =>
      asset.hasLocal && 
      (!asset.hasRemote || !AppSetting.get(Setting.preferRemoteImage));
  ```

**选择决策树**：
```
资源是否有本地文件？
  ├─ 是
  │  ├─ 资源是否有远程版本？
  │  │  ├─ 是 → 检查用户偏好
  │  │  │  ├─ preferRemoteImage = false → 使用本地资源 ✅
  │  │  │  └─ preferRemoteImage = true → 使用远程资源 ✅
  │  │  └─ 否 → 使用本地资源 ✅
  │  └─ 使用本地资源 ✅
  └─ 否 → 使用远程资源 ✅
```

### 2. 加载层

#### 2.1 LocalImageRequest

**功能**：
- 从本地文件系统读取图片
- 使用 `photo_manager` 生成缩略图
- 支持指定尺寸和质量

**实现细节**：
- **图片资源**：直接读取原文件路径
- **视频资源**：调用 `thumbnailDataWithSize` 生成缩略图
- **错误处理**：文件不存在或读取失败时抛出异常

**代码示例**：
```dart
class LocalImageRequest extends ImageRequest {
  final AssetEntity asset;
  final Size targetSize;
  
  @override
  Future<ui.Codec> load() async {
    if (asset.type == AssetType.image) {
      final file = await asset.originFile;
      if (file == null) throw Exception('File not found');
      final buffer = await ui.ImmutableBuffer.fromFilePath(file.path);
      return await ui.instantiateImageCodec(buffer);
    } else {
      final thumbnail = await asset.thumbnailDataWithSize(
        ThumbnailSize(targetSize.width.toInt(), targetSize.height.toInt()),
        quality: 80,
      );
      if (thumbnail == null) throw Exception('Thumbnail generation failed');
      final buffer = await ui.ImmutableBuffer.fromUint8List(thumbnail);
      return await ui.instantiateImageCodec(buffer);
    }
  }
}
```

#### 2.2 RemoteImageRequest

**功能**：
- 从网络下载图片
- 支持流式下载和进度报告
- 自动处理缓存

**实现细节**：
- **HTTP 客户端**：使用 `HttpClient`，最大 16 个并发连接
- **缓存检查**：
  1. 先检查内存缓存（快速路径）
  2. 再检查磁盘缓存
  3. 最后从网络下载
- **流式处理**：支持边下载边解码，提升感知速度
- **错误恢复**：网络失败时回退到磁盘缓存

**代码示例**：
```dart
class RemoteImageRequest extends ImageRequest {
  final String url;
  final CacheManager cacheManager;
  
  @override
  Future<ui.Codec> load() async {
    // 1. 检查内存缓存
    final cachedImage = await _checkMemoryCache(url);
    if (cachedImage != null) return cachedImage;
    
    // 2. 检查磁盘缓存
    final fileInfo = await cacheManager.getFileFromCache(url);
    if (fileInfo != null) {
      final buffer = await ui.ImmutableBuffer.fromFilePath(fileInfo.file.path);
      return await ui.instantiateImageCodec(buffer);
    }
    
    // 3. 从网络下载
    final stream = await cacheManager.getFileStream(url);
    final file = await stream.first;
    final buffer = await ui.ImmutableBuffer.fromFilePath(file.path);
    return await ui.instantiateImageCodec(buffer);
  }
}
```

#### 2.3 ImageLoader

**功能**：
- 统一的图片加载接口
- 集成缓存管理器
- 支持进度事件

**工作流程**：
1. 调用 `CacheManager.getFileStream()` 获取文件流
2. 监听下载进度，发送 `ImageChunkEvent`
3. 文件就绪后解码为 `Codec`
4. 返回解码后的图片

### 3. 缓存层

#### 3.1 CustomImageCache（内存缓存）

**三级缓存结构**：

```
CustomImageCache
├─ _thumbhash (ThumbHash 缓存)
│  └─ maximumSize = 0 (无限制，临时存储)
├─ _small (小图缓存)
│  └─ 用于缩略图，容量较大
└─ _large (大图缓存)
   └─ maximumSize = 5 (最多 5 张)
```

**路由规则**：
- **大图缓存**：`LocalFullImageProvider`、`RemoteFullImageProvider`
- **小图缓存**：`LocalThumbProvider`、`RemoteThumbProvider`
- **ThumbHash 缓存**：`ThumbHashProvider`

**优势**：
- 防止大图驱逐小图
- 优化内存使用
- 提升缓存命中率

**实现要点**：
```dart
class CustomImageCache extends ImageCache {
  final ImageCache _thumbhash = ImageCache();
  final ImageCache _small = ImageCache();
  final ImageCache _large = ImageCache()..maximumSize = 5;
  
  ImageCache _getCacheForProvider(ImageProvider provider) {
    if (provider is ThumbHashProvider) return _thumbhash;
    if (provider is LocalFullImageProvider || 
        provider is RemoteFullImageProvider) return _large;
    return _small;
  }
  
  @override
  ImageStream resolveStream(ImageConfiguration configuration, ImageProvider provider) {
    final cache = _getCacheForProvider(provider);
    return cache.resolveStream(configuration, provider);
  }
}
```

#### 3.2 CacheManager（磁盘缓存）

**ThumbnailImageCacheManager**
- **用途**：存储缩略图
- **配置**：最多 5000 个对象，30 天过期
- **存储位置**：应用缓存目录

**RemoteImageCacheManager**
- **用途**：存储远程原图
- **配置**：最多 500 个对象，30 天过期
- **存储位置**：应用缓存目录

**缓存策略**：
- **LRU 淘汰**：超出数量限制时淘汰最久未使用的
- **过期清理**：超过过期时间的自动清理
- **流式存储**：支持边下载边存储，不占用额外内存

**实现要点**：
```dart
class ThumbnailImageCacheManager extends CacheManager {
  static const key = 'thumbnail-cache';
  
  ThumbnailImageCacheManager()
      : super(
          Config(
            key,
            maxNrOfCacheObjects: 5000,
            stalePeriod: const Duration(days: 30),
          ),
        );
}

class RemoteImageCacheManager extends CacheManager {
  static const key = 'remote-image-cache';
  
  RemoteImageCacheManager()
      : super(
          Config(
            key,
            maxNrOfCacheObjects: 500,
            stalePeriod: const Duration(days: 30),
          ),
        );
}
```

### 4. ThumbHash 支持

#### 4.1 ThumbHashProvider

**功能**：
- 解码 ThumbHash 字节数组
- 生成低分辨率占位图
- 提供即时视觉反馈

**使用场景**：
- 远程资源（`RemoteAsset`）
- 资源有 `thumbHash` 字段
- 资源无本地文件（`localId == null`）

**解码流程**：
1. 读取 ThumbHash 字节：从资源对象获取
2. 解析头部信息：亮度、色度、尺寸、Alpha 通道
3. 生成像素数据：使用 DCT 变换重建图片
4. 创建 Image 对象：转换为 Flutter Image

**代码示例**：
```dart
class ThumbHashProvider extends ImageProvider<ThumbHashProvider> {
  final Uint8List thumbHash;
  
  @override
  Future<ImageInfo> loadImage(ImageProvider key, ImageDecoderCallback decode) async {
    // 解码 ThumbHash
    final image = decodeThumbHash(thumbHash);
    final codec = await ui.instantiateImageCodec(
      await ui.ImmutableBuffer.fromUint8List(image),
    );
    final frame = await codec.getNextFrame();
    return ImageInfo(image: frame.image);
  }
}
```

### 5. 渐变占位符

#### 5.1 GradientPlaceholderProvider

**功能**：
- 生成基于主题色的渐变占位符
- 作为 ThumbHash 的后备方案
- 提供视觉一致性

**实现方式**：
- 从主题色方案获取：`colorScheme.surfaceContainer`
- 生成渐变：从浅色到深色
- 按颜色方案缓存渐变对象

**代码示例**：
```dart
class GradientPlaceholderProvider extends ImageProvider<GradientPlaceholderProvider> {
  final ColorScheme colorScheme;
  
  @override
  Future<ImageInfo> loadImage(ImageProvider key, ImageDecoderCallback decode) async {
    final gradient = LinearGradient(
      colors: [
        colorScheme.surfaceContainer,
        colorScheme.surfaceContainerHighest,
      ],
    );
    // 生成渐变图片
    final image = _generateGradientImage(gradient);
    return ImageInfo(image: image);
  }
}
```

### 1. 三级内存缓存实现

#### 1.1 缓存池分离

**设计原因**：
- **防止大图驱逐小图**：单张大图（如 50MB）可能挤占内存，导致数百张缩略图被驱逐
- **独立 LRU 策略**：大图池独立，确保查看器中的大图不会影响列表缩略图
- **提升缓存命中率**：各池独立管理，避免相互干扰

**实现要点**：
```dart
class CustomImageCache extends ImageCache {
  // 三级缓存池
  final ImageCache _thumbhash = ImageCache();
  final ImageCache _small = ImageCache();
  final ImageCache _large = ImageCache()..maximumSize = 5;
  
  // 根据 Provider 类型路由到对应缓存池
  ImageCache _getCacheForProvider(ImageProvider provider) {
    if (provider is ThumbHashProvider) return _thumbhash;
    if (provider is LocalFullImageProvider || 
        provider is RemoteFullImageProvider) return _large;
    return _small;
  }
  
  @override
  ImageStream resolveStream(
    ImageConfiguration configuration,
    ImageProvider provider,
  ) {
    final cache = _getCacheForProvider(provider);
    return cache.resolveStream(configuration, provider);
  }
  
  // 清理所有缓存
  @override
  void clear() {
    _thumbhash.clear();
    _small.clear();
    _large.clear();
  }
  
  // 清理特定类型的缓存
  void evictLargeImages() => _large.clear();
  void evictSmallImages() => _small.clear();
}
```

#### 2.2 流式存储优化

**实现要点**：
- 使用 `getFileStream()` 支持边下载边存储
- 下载被取消时自动清理未完成的文件
- 使用 UUID 生成临时文件名，避免冲突
- 仅在文件完全写入后才写入数据库记录，保证一致性

```dart
class RemoteImageRequest extends ImageRequest {
  final String url;
  final CacheManager cacheManager;
  StreamSubscription? _downloadSubscription;
  bool _isCancelled = false;
  
  @override
  Future<ui.Codec> load() async {
    try {
      // 检查磁盘缓存
      final fileInfo = await cacheManager.getFileFromCache(url);
      if (fileInfo != null && !_isCancelled) {
        final buffer = await ui.ImmutableBuffer.fromFilePath(fileInfo.file.path);
        return await ui.instantiateImageCodec(buffer);
      }
      
      // 从网络下载
      final stream = cacheManager.getFileStream(url);
      _downloadSubscription = stream.listen(
        (fileResponse) {
          if (fileResponse is DownloadProgress) {
            // 发送进度事件
            _onProgress(fileResponse.progress);
          } else if (fileResponse is FileInfo && !_isCancelled) {
            // 文件就绪，解码
            _decodeFile(fileResponse.file);
          }
        },
        onError: (error) {
          if (!_isCancelled) {
            throw error;
          }
        },
      );
      
      // 等待文件就绪
      final fileInfo = await stream.first;
      if (_isCancelled) throw Exception('Cancelled');
      
      final buffer = await ui.ImmutableBuffer.fromFilePath(fileInfo.file.path);
      return await ui.instantiateImageCodec(buffer);
    } catch (e) {
      if (_isCancelled) {
        // 取消时清理未完成的文件
        await cacheManager.removeFile(url);
      }
      rethrow;
    }
  }
  
  @override
  void cancel() {
    _isCancelled = true;
    _downloadSubscription?.cancel();
  }
}
```

### 3. ThumbHash 解码实现

#### 3.1 解码流程

**实现要点**：
1. 读取 ThumbHash 字节数组（通常 < 100 字节）
2. 解析头部信息（亮度、色度、尺寸、Alpha 通道）
3. 使用 DCT 变换重建图片
4. 转换为 Flutter Image 对象

```dart
class ThumbHashProvider extends ImageProvider<ThumbHashProvider> {
  final Uint8List thumbHash;
  
  const ThumbHashProvider(this.thumbHash);
  
  @override
  Future<ImageInfo> loadImage(
    ImageProvider key,
    ImageDecoderCallback decode,
  ) async {
    // 解码 ThumbHash
    final decodedImage = _decodeThumbHash(thumbHash);
    
    // 转换为 Codec
    final buffer = await ui.ImmutableBuffer.fromUint8List(decodedImage);
    final codec = await ui.instantiateImageCodec(buffer);
    final frame = await codec.getNextFrame();
    
    return ImageInfo(image: frame.image);
  }
  
  Uint8List _decodeThumbHash(Uint8List thumbHash) {
    // ThumbHash 解码实现
    // 1. 解析头部信息
    final header = _parseHeader(thumbHash);
    
    // 2. 解码亮度通道
    final luma = _decodeLuma(thumbHash, header);
    
    // 3. 解码色度通道
    final chroma = _decodeChroma(thumbHash, header);
    
    // 4. 重建像素数据
    return _reconstructImage(luma, chroma, header);
  }
  
  @override
  bool operator ==(Object other) =>
      identical(this, other) ||
      other is ThumbHashProvider &&
          runtimeType == other.runtimeType &&
          _listEquals(thumbHash, other.thumbHash);
  
  @override
  int get hashCode => thumbHash.hashCode;
}
```

#### 6.1 CancellableImageProvider

```dart
mixin CancellableImageProviderMixin<T extends ImageProvider<T>> on ImageProvider<T> {
  bool _isCancelled = false;
  ImageRequest? _currentRequest;
  
  bool get isCancelled => _isCancelled;
  
  void cancel() {
    _isCancelled = true;
    _currentRequest?.cancel();
    _currentRequest = null;
  }
  
  @override
  Future<ImageInfo> loadImage(
    ImageProvider key,
    ImageDecoderCallback decode,
  ) async {
    if (_isCancelled) {
      throw Exception('Image loading cancelled');
    }
    
    try {
      final request = createImageRequest();
      _currentRequest = request;
      
      if (_isCancelled) {
        request.cancel();
        throw Exception('Image loading cancelled');
      }
      
      final codec = await request.load();
      
      if (_isCancelled) {
        codec.dispose();
        throw Exception('Image loading cancelled');
      }
      
      final frame = await codec.getNextFrame();
      return ImageInfo(image: frame.image);
    } finally {
      _currentRequest = null;
    }
  }
  
  ImageRequest createImageRequest();
}
```

#### 7.1 可见性检测

```dart
class MediaGridView extends StatefulWidget {
  final List<BaseAsset> assets;
  
  @override
  State<MediaGridView> createState() => _MediaGridViewState();

class _MediaGridViewState extends State<MediaGridView> {
  final Set<String> _visibleAssets = {};
  
  @override
  Widget build(BuildContext context) {
    return GridView.builder(
      itemCount: widget.assets.length,
      itemBuilder: (context, index) {
        final asset = widget.assets[index];
        return VisibilityDetector(
          key: Key(asset.id),
          onVisibilityChanged: (info) {
            if (info.visibleFraction > 0.1) {
              // 可见时开始加载
              _visibleAssets.add(asset.id);
              _preloadAdjacentAssets(index);
            } else {
              // 不可见时取消加载
              _visibleAssets.remove(asset.id);
              _cancelLoading(asset);
            }
          },
          child: MediaImageWidget(asset: asset),
        );
      },
    );
  }
  
  void _preloadAdjacentAssets(int index) {
    // 预加载前后几张图片
    for (int i = -2; i <= 2; i++) {
      final targetIndex = index + i;
      if (targetIndex >= 0 && targetIndex < widget.assets.length) {
        final asset = widget.assets[targetIndex];
        if (!_visibleAssets.contains(asset.id)) {
          _preloadImage(asset);
        }
      }
    }
  }
  
  void _preloadImage(BaseAsset asset) {
    final provider = getThumbnailImageProvider(asset);
    if (provider != null) {
      // 预加载到内存缓存
      precacheImage(provider, context);
    }
  }
  
  void _cancelLoading(BaseAsset asset) {
    // 取消加载逻辑
    final provider = getThumbnailImageProvider(asset);
    if (provider is CancellableImageProviderMixin) {
      provider.cancel();
    }
  }
}
```

```dart
class MultiImageStreamCompleter extends ImageStreamCompleter {
  final List<Future<ui.Codec>> _codecFutures = [];
  bool _isDisposed = false;
  
  void addCodec(Future<ui.Codec> codecFuture) {
    if (_isDisposed) return;
    
    _codecFutures.add(codecFuture);
    codecFuture.then((codec) {
      if (_isDisposed) {
        codec.dispose();
        return;
      }
      
      codec.getNextFrame().then((frame) {
        if (!_isDisposed) {
          setImage(ImageInfo(image: frame.image));
        }
      });
    });
  }
  
  @override
  void dispose() {
    _isDisposed = true;
    // 取消所有未完成的加载
    for (final future in _codecFutures) {
      future.then((codec) => codec.dispose());
    }
    super.dispose();
  }
}
```

```dart
        // 视频缩略图生成
        final thumbnail = await asset.thumbnailDataWithSize(
          ThumbnailSize(targetSize.width.toInt(), targetSize.height.toInt()),
        );
        if (thumbnail == null) {
          throw FileSystemImageException(
            message: 'Thumbnail generation failed',
            filePath: asset.id,
          );
        }
        final buffer = await ui.ImmutableBuffer.fromUint8List(thumbnail);
        return await ui.instantiateImageCodec(buffer);
      }
    } on FileSystemImageException catch (e) {
      _logError(e);
      rethrow;
    }
  }
  
  void _logError(FileSystemImageException e) {
    logger.error('Failed to load local image: ${e.filePath}', error: e);
  }
}
```

### 3. 自动恢复机制

#### 3.1 缓存回退

```dart
class RemoteImageRequest extends ImageRequest {
  @override
  Future<ui.Codec> load() async {
    // 1. 尝试从内存缓存加载
    final memoryCache = await _loadFromMemoryCache();
    if (memoryCache != null) return memoryCache;
    
    // 2. 尝试从磁盘缓存加载
    final diskCache = await _loadFromDiskCache();
    if (diskCache != null) return diskCache;
    
    // 3. 尝试从网络下载
    try {
      return await _loadFromNetwork();
    } catch (e) {
      // 网络失败，再次尝试使用磁盘缓存（可能刚过期）
      final staleCache = await _loadStaleCache();
      if (staleCache != null) {
        logger.info('Using stale cache due to network failure');
        return staleCache;
      }
      rethrow;
    }
  }
}
```

#### 3.2 重试机制

```dart
class RemoteImageRequest extends ImageRequest {
  static const maxRetries = 3;
  static const retryDelay = Duration(seconds: 1);
  
  @override
  Future<ui.Codec> load() async {
    int retries = 0;
    
    while (retries < maxRetries) {
      try {
        return await _loadFromNetwork();
      } on NetworkImageException catch (e) {
        retries++;
        if (retries >= maxRetries) {
          rethrow;
        }
        
        // 指数退避
        final delay = retryDelay * (1 << (retries - 1));
        await Future.delayed(delay);
      }
    }
    
    throw Exception('Max retries exceeded');
  }
}
```

### 2. 加载优化策略

#### 2.1 预加载策略

**实现要点**：

- 可见性检测，仅加载可见区域
- 离开视口时取消加载

```dart
class MediaGridView extends StatefulWidget {
  @override
  State<MediaGridView> createState() => _MediaGridViewState();
}

class _MediaGridViewState extends State<MediaGridView> {
  final ScrollController _scrollController = ScrollController();
  final Set<int> _visibleIndices = {};
  
  @override
  void initState() {
    super.initState();
    _scrollController.addListener(_onScroll);
  }
  
  void _onScroll() {
    final viewport = _scrollController.position.viewportDimension;
    final offset = _scrollController.offset;
    
    // 计算可见区域
    final startIndex = (offset / _itemHeight).floor();
    final endIndex = ((offset + viewport) / _itemHeight).ceil();
    
    // 预加载可见区域前后各 2 个
    for (int i = startIndex - 2; i <= endIndex + 2; i++) {
      if (i >= 0 && i < widget.assets.length) {
        if (!_visibleIndices.contains(i)) {
          _visibleIndices.add(i);
          _preloadImage(widget.assets[i]);
        }
      }
    }
    
    // 取消不可见区域的加载
    _visibleIndices.removeWhere((index) {
      if (index < startIndex - 3 || index > endIndex + 3) {
        _cancelLoading(widget.assets[index]);
        return true;
      }
      return false;
    });
  }
  
  void _preloadImage(BaseAsset asset) {
    final provider = getThumbnailImageProvider(asset);
    if (provider != null) {
      precacheImage(provider, context);
    }
  }
  
  void _cancelLoading(BaseAsset asset) {
    final provider = getThumbnailImageProvider(asset);
    if (provider is CancellableImageProviderMixin) {
      provider.cancel();
    }
  }
}
```

### 4. 常见问题和解决方案

#### 4.1 内存溢出（OOM）

**问题**：加载大量图片时出现内存溢出

**解决方案**：
- 严格控制大图缓存数量（最多 5 张）
- 及时清理不再使用的图片
- 使用适配设备分辨率的图片，避免加载过大图片

#### 4.2 缓存命中率低

**问题**：缓存命中率低，频繁从网络下载

**解决方案**：
- 检查缓存键生成逻辑，确保唯一性
- 增加缓存容量（在合理范围内）
- 优化缓存过期时间

#### 4.3 加载速度慢

**问题**：图片加载速度慢，用户体验差

**解决方案**：
- 优先使用本地资源
- 实现预加载策略
- 优化网络请求（连接复用、并发控制）
- 使用流式加载，边下载边显示

#### 4.4 占位符显示异常

**问题**：占位符显示不正确或闪烁

**解决方案**：
- 检查 ThumbHash 解码逻辑
- 优化占位符切换动画
- 确保占位符尺寸正确

### 5. 最佳实践

#### 5.1 ImageProvider 使用

**正确做法**：
```dart
// 使用工厂方法获取 Provider
final provider = getThumbnailImageProvider(asset);
if (provider != null) {
  return Image(image: provider);
}
```

**错误做法**：
```dart
// 不要直接创建 Provider
final provider = LocalThumbProvider(asset: asset.local!); // ❌
```

#### 5.2 缓存管理

**正确做法**：
```dart
// 使用统一的缓存管理器
final cacheManager = ref.read(thumbnailCacheManagerProvider);
final fileInfo = await cacheManager.getFileFromCache(url);
```

**错误做法**：
```dart
// 不要直接操作文件系统
final file = File('cache/$url'); // ❌
```

#### 5.3 错误处理

**正确做法**：
```dart
return Image(
  image: provider,
  errorBuilder: (context, error, stackTrace) {
    return ImageErrorWidget(error: error);
  },
);
```

**错误做法**：
```dart
// 不要忽略错误
return Image(image: provider); // ❌ 没有错误处理
```

## 总结

媒体资源展示模块是 PrismBox 移动端的核心展示模块，通过以下核心机制实现了高效、流畅的媒体加载体验：

### 核心设计亮点

1. **多级渐进式加载**：占位符 → 缩略图 → 预览图 → 原图的渐进式加载策略，确保快速首屏显示
2. **智能资源选择**：根据本地/远程资源可用性和用户偏好自动选择最优资源提供者
3. **三级内存缓存分离**：ThumbHash、小图、大图分离缓存，防止相互驱逐，优化内存使用
4. **多级磁盘缓存**：缩略图和远程图片使用独立的缓存管理器，精细化控制缓存策略
5. **占位符优化**：ThumbHash 和渐变占位符提供即时视觉反馈，提升用户体验
6. **可取消加载**：支持加载任务取消，避免资源浪费和内存泄漏
7. **流式加载**：支持边下载边解码，提升感知速度

### 性能指标

- **缩略图加载时间**：< 100ms（缓存命中）
- **预览图加载时间**：< 500ms（WiFi 环境）
- **原图加载时间**：< 2s（WiFi 环境）
- **内存占用**：< 200MB（正常使用）
- **缓存命中率**：> 80%（正常使用场景）

### 技术特点

- **类型安全**：充分利用 Dart 的类型系统，编译时检查
- **平台原生集成**：充分利用 Android MediaStore 和 iOS PHPhotoLibrary
- **可扩展性**：清晰的接口设计，易于扩展新功能
- **错误恢复**：完善的错误处理和自动恢复机制

### 后续优化方向

1. **智能预加载**：基于用户行为预测，提前加载可能需要的图片
2. **自适应质量**：根据网络条件自动调整图片质量
3. **WebP 支持**：支持 WebP 格式，进一步优化文件大小
4. **视频缩略图优化**：优化视频缩略图生成和缓存策略
5. **离线模式增强**：增强离线浏览能力，支持离线缓存管理
